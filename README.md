# regime-lab

> **과거 데이터 분석 도구이며 투자 권유가 아닙니다.** (Historical analysis — not investment advice.)
> 목표가·투자 비중·종목 추천·매매 신호를 제공하지 않습니다.

regime-lab은 **코스피·코스닥 일봉 데이터로 기술적 매매 패턴을 백테스트하고, 그 성과가 시장 환경에 따라 어떻게 달라지는지 확인하는 분석 서비스**입니다.

"이 패턴이 과거에 수익을 냈는가?"에서 한 걸음 더 나아가 다음을 함께 확인합니다.

- 상승장·횡보장·하락장 중 **어떤 국면에서** 성과가 났는가?
- **대형주·중형주·소형주**, 코스피·코스닥 중 어디에서 성과가 났는가?
- 그 성과가 **우연이 아니라고 볼 근거**가 있는가? (3중 검증)

## 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 전략 만들기 | 고정된 패턴 5종을 AND/OR로 조합하고, 손절·익절·최대 보유 기간, 시장·기간·거래대금 하한·시총 그룹을 정합니다 |
| 백테스트 | 신호 다음 날 시가에 매수하고, 상한가·하한가·거래정지·상장폐지, 왕복 비용 0.30%를 반영합니다 |
| 국면별 분석 | 시장 국면 × 시장 × 시가총액 그룹별 성과를 표시하고, 거래 300건 미만 칸은 "표본 부족"으로 구분합니다 |
| 3중 검증 | ① 기간 분할(2024-02-29 전후) ② 다중검정 보정(BH-FDR) ③ 무작위 진입 1,000회 비교. 셋 다 통과해야 "분석 대상"으로 표시합니다 |
| 종목 상세 | 가격·이동평균·국면 배경 위에 과거 매매 시점을 표시하고, 단순 보유와 비교합니다 |
| AI 보고서 | 결과를 한국어로 해설합니다. 결과에 없는 숫자나 권유 표현이 나오면 자동으로 막습니다 |

**사용 데이터**: 코스피·코스닥 전 종목 일봉, 2020-09-01 ~ 2026-09-18 (상장폐지 종목 포함)

**핵심 패턴 5종**

| 패턴 | 조건 |
|---|---|
| 5/20 골든크로스 | 5일선이 20일선을 상향 돌파 |
| 20일 고가 돌파 | 종가가 직전 20거래일 최고가를 넘음 |
| 거래량 동반 돌파 | 20일 고가 돌파 + 거래량이 직전 20일 평균의 2배 이상 |
| RSI 30 회복 | RSI(14)가 30 아래에서 30 이상으로 회복 |
| 볼린저 하단 회복 | 종가가 볼린저 하단(20일, 2σ) 아래에서 다시 위로 |

## 빠른 시작

### 준비물

- Windows / macOS / Linux, **Python 3.12**, [uv](https://docs.astral.sh/uv/)
- 메모리 8GB 이상 (실행 중 최대 약 2.4GB 사용)
- 원본 데이터: 저장소 루트에 `store/`(시세 데이터)와 `multi_tables_db/`(SQL 덤프). **저장소에는 포함되지 않습니다.**

### 처음 한 번

아래 명령은 모두 **저장소 루트**(`regime-lab/`)에서 실행합니다.

1. 패키지를 설치합니다.

```bash
uv sync --project engine
```
```bash
uv sync --project api
```

2. SQL 덤프에서 워밍업용 가격과 참조값을 추출합니다(약 20초, 결과는 `cache/`에 저장).

```bash
uv run --project engine python engine/scripts/extract_sqldump.py
```

3. 분석용 데이터를 미리 계산해 둡니다(약 40초). 이후 서버는 1초 안에 데이터를 불러옵니다.

```bash
uv run --project engine regime-lab prepare
```

### 실행

```bash
uv run --project api regime-api
```

브라우저에서 **http://127.0.0.1:8000** 을 엽니다. 끌 때는 서버를 실행한 창에서 `Ctrl+C`를 누릅니다.

## 사용 방법

### 1. 시작하기

첫 화면에서 **게스트 모드로 진행**을 누르면 가입 없이 바로 사용할 수 있습니다. 로그인·계정 만들기는 화면 흐름만 있는 데모이며, 실제 인증이나 계정 저장은 하지 않습니다.

### 2. 전략 만들기 — 전략 빌더

| 영역 | 입력 |
|---|---|
| 매수 조건 | 패턴을 1개 이상 고르고, 여러 개면 AND(모두 충족) 또는 OR(하나라도 충족)를 고릅니다 |
| 매도·청산 규칙 | 손절(-50 ~ -1%), 익절(+1 ~ +200%), 최대 보유(1 ~ 250거래일). 손절·익절은 "사용"을 끄면 적용하지 않습니다 |
| 유니버스·기간 | 시장, 신호 기간, 20일 평균 거래대금 하한(5억 원 이상), 시총 그룹 |

조건을 바꾸면 카드 아래에 **예상 대상 종목 수**가 바로 표시됩니다. 우측 하단에 전략 이름을 적고 **백테스트 실행**을 누르세요. 입력이 허용 범위를 벗어나면 해당 칸 아래에 이유가 표시되고 실행되지 않습니다.

### 3. 진행 상황

필터 → 로드 → 지표 → 신호 → 국면 → 집계 → 저장 단계가 순서대로 표시됩니다. 전 종목 기준 약 13초 걸리며, 끝나면 결과 화면으로 자동 이동합니다. **실행 취소**를 누르면 결과를 남기지 않고 중단합니다.

> 한 번에 하나의 실행만 할 수 있습니다. 실행 중에 다시 실행하면 진행 중인 화면으로 이동합니다.

### 4. 결과 읽기

| 영역 | 보는 법 |
|---|---|
| 검증 3종 | 기간 분할·거짓 발견 통제·무작위 벤치마크의 통과 여부. **셋 다 통과해야 "분석 대상"**입니다 |
| 성과 카드 | 거래 수, 승률, 평균 수익(비용 차감 후), 시장 대비 초과수익, 무작위 백분위, 최대낙폭 등 |
| 무작위 백분위 | "39.7 백분위 · 무작위 1,000회 중 39.7%보다 높음"은 같은 종목·보유기간으로 무작위 진입한 결과보다 얼마나 나은지를 뜻합니다(수익률이 아님) |
| 자산곡선 | 동시 보유 종목을 같은 비중으로 담았을 때의 일별 자산. 아래 막대를 끌어 기간을 확대할 수 있습니다 |
| 국면 × 시가총액 | 국면별·시총 그룹별 평균 초과수익. **빗금 칸은 거래 300건 미만**이라 결론에 쓰지 않습니다 |
| 종목 표 | 수익률이 아니라 **거래 수 순**으로 정렬합니다. 행을 누르면 종목 상세로 이동합니다 |

각 지표의 계산식은 결과 화면 맨 아래 **지표 정의**에서 볼 수 있습니다.

### 5. 종목 상세와 AI 보고서

- **종목 상세**: 가격과 20·200일선, 종목 국면(상승 초록·하락 빨강 배경), 과거 진입▲·청산■ 시점, 거래 내역을 보여 줍니다.
- **AI 보고서**: 같은 실행 결과를 한국어로 해설합니다. 상단 표시로 종류를 구분합니다.
  - **숫자 검증 통과**: AI가 쓴 문장이 검증을 통과한 경우
  - **템플릿 보고서**: AI를 쓸 수 없거나 검증에 실패해 정해진 문장으로 대신한 경우

### 6. 설정

사이드바 맨 아래 **⚙ 설정**에서 화면 언어를 **한국어(기본) / English**로 바꿀 수 있습니다. 선택은 이 브라우저에 저장됩니다. AI 보고서 본문은 언어 설정과 관계없이 한국어입니다.

> **모닝 브리핑**은 야간 시세·뉴스 데이터가 아직 없어 "데이터 없음"만 표시합니다(추후 과제).

## ChatGPT 보고서 켜기 (선택)

키가 없으면 AI 보고서는 템플릿으로 동작합니다. ChatGPT를 쓰려면 서버를 켜기 전에 환경변수를 설정합니다(PowerShell 예시).

```powershell
$env:REGIME_LLM_MODEL = "<사용할 OpenAI 모델명>"
```
```powershell
$env:OPENAI_API_KEY = "<발급받은 키>"
```
```powershell
uv run --project api regime-api
```

API 키는 코드나 파일에 적지 말고 환경변수로만 넣으세요. AI에는 집계된 결과 수치만 보내고, 원본 시세나 개인정보는 보내지 않습니다.

## 명령줄로 사용하기 (선택)

화면 없이 전략 파일(YAML)로 실행할 수도 있습니다. 결과는 `runs/<실행 ID>/`에 저장됩니다.

전략 1개 실행:
```bash
uv run --project engine regime-lab run engine/strategies/core_breakout_vol.yaml
```

여러 전략 비교 실행(한 번의 실행으로 묶어 다중검정 보정을 적용):
```bash
uv run --project engine regime-lab run engine/strategies/core_breakout_20d.yaml engine/strategies/core_breakout_vol.yaml
```

핵심 5종 한꺼번에 실행(약 75초):
```bash
uv run --project engine regime-lab batch
```

전략 파일 작성법은 `engine/strategies/example_breakout_and_rsi.yaml`을 참고하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `error while attempting to bind on address ('127.0.0.1', 8000)` | 이미 서버가 켜져 있습니다. 기존 창에서 `Ctrl+C`로 끄거나 다른 포트를 씁니다: `$env:REGIME_PORT = "8001"; uv run --project api regime-api` |
| 화면에 "데이터 불러오는 중"이 계속 표시됨 | 분석용 데이터를 계산하는 중입니다. `regime-lab prepare`를 먼저 실행해 두면 1초 안에 뜹니다 |
| AI 보고서가 "템플릿 보고서"로 나옴 | 모델명·키가 설정되지 않았거나 AI 문장이 검증에서 걸렸습니다. 화면의 대체 사유를 확인하세요 |
| 종목 상세에 "오래된 결과" 표시 | 설정이나 데이터가 바뀌기 전의 실행입니다. 다시 실행하세요 |
| 30종목으로 빠르게 시험하고 싶음 | `$env:REGIME_SAMPLE = "1"`을 설정한 뒤 서버를 켭니다 |

## 프로젝트 구성

```text
regime-lab/
├─ engine/     분석 엔진 (Python) — 데이터·지표·국면·패턴·백테스트·검증, CLI
├─ api/        실행·결과 API (FastAPI) — 웹 화면 서빙, AI 보고서
├─ web/        웹 화면 (HTML/JavaScript) — 한국어·영어
├─ docs/       기획·결정·계획 문서
├─ store/      원본 시세 데이터 (저장소 미포함)
├─ cache/      추출·계산 데이터 (자동 생성, 저장소 미포함)
└─ runs/       실행 결과 (자동 생성, 저장소 미포함)
```

테스트:
```bash
uv run --project engine pytest engine
```
```bash
uv run --project api pytest api
```

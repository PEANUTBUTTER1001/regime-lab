# 외부 자료 출처 대장

활성은 아래 명시한 수집·보관 범위에만 적용. API 접근과 제3자 재배포·LLM 전송 허용은 별개다.
2026-10-17 사용자 DART·ECOS SRS 및 `$execute` 승인 근거. 운영자가 동의한 제공기관 조건을 준수한다.
실서버 인증 호출·적재·예약 실행은 별도 수용 사항이며, 출처 활성 자체가 운영 성공 증거는 아니다.

| 출처 | 활성 범위 | 보관·사용 | 전송·표시 | 승인 근거 |
|---|---|---|---|---|
| OpenDART 공시검색 목록 | 활성 | 기존 metadata_only 목록·날짜·회사·접수번호, 기존 ingest 계약 유지 | 제목·DART 원문 링크, 기존 제품 범위 | 기존 D-4·P3_수집_계약 |
| OpenDART 회사 식별정보·기업개황 | 신규 수집 활성 | corpCode ZIP의 회사정보·company JSON, fund_* 서버 DB 원본/변경 이력 | 이번 구현에서 제품 반영·LLM 전송 없음 | DART·ECOS SRS, 2026-10-17 사용자 승인 |
| OpenDART 사건 상세·재무 | 신규 수집 활성 | 선정 사건12종·fnlttSinglAcntAll JSON 전체, fund_* 서버 DB, 향후 학습 재료 | 공시 원문 ZIP·제품 반영·LLM 전송 없음 | 같은 승인, D-4 보관 범위 확대 |
| 한국은행 ECOS | 신규 수집 활성 | 통계표/항목 메타, 기준금리·국고채3/10년·회사채AA-3년·원/달러 매매기준율5계열, fund_* 서버 DB | 이번 구현에서 제품 반영·LLM 전송 없음 | 같은 승인, 신규 출처 |
| 기존 n8n_news/n8n_disclosure 스냅샷 | 신규 활성화 아님 | 기존 local_fixture·coverage unknown 개발/평가 범위 유지 | 이 문서 작성으로 서비스 활성·권한 확대하지 않음 | 기존 F1c·F1d 유지 |
| 네이버 뉴스·RSS·기타 | 이번 작업의 활성 대상 아님 | 기존 설정·승인 상태 유지 | 이 작업에서 수집·LLM 범위 확대 없음 | 기존 계약 유지 |

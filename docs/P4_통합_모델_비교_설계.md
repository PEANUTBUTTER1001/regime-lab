# P4-3 통합 모델·가격 단독 비교 — 설계 초안

> WBS P4-3 (담당 Seonghwanaa) · 선행 P4-2(hchee99)·P2-8·X5·P2-10 · SRS FR-B2·C-8·NFR-4 · 기획 [`plan/04`](plan/04-fusion-and-briefing.md) 작업 ⑩
> 상태: **제안**. 구현은 P4-2 특징 계약과 P3-12 결과 계약이 정해진 뒤 시작한다. 이 문서는 그 전에 비교 방법·판정 기준·입력 계약 초안을 정해 두려는 것이다.

## 1. 무엇을 비교하나

- **가격 단독**: P2 봉 예측 모델 그대로 (`forecast/model.py`, 특징 17개 `FEATURES`, 분위 회귀 + 상승 확률, 검증 앞 절반 보정).
- **통합**: 같은 모델 구조에 P4-2 외부 자료 특징 열을 더한 것. 모델 종류·하이퍼파라미터·시드·분할·보정 방식은 가격 단독과 같게 둔다. 차이를 입력 특징 하나로 좁혀야 개선 원인을 말할 수 있다.
- **단순 기준선**: P2-5 과거 분위 기준선 (`forecast/baseline.py`). 세 결과를 같은 표에 둔다 (FR-B2, 기획 ⑫).

`model.fit(X_train, …)` 은 특징 열 목록에 묶여 있지 않으므로 통합 모델은 `X = feats[FEATURES + EXT_FEATURES]` 로 같은 함수를 쓴다. 새 모델 모듈은 만들지 않는다 (R7).

## 2. 비교 조건 (같아야 하는 것)

| 항목 | 규칙 |
|---|---|
| 표본 | 같은 종목·봉 단위·`as_of`·예측 길이 h. 두 모델이 모두 예측한 표본의 교집합만 채점 |
| 분할 | `forecast.split` 그대로 (학습 → 검증 앞 절반 보정 → 검증 뒤 절반 방향 판정 → 최종 평가). 외부 자료가 없는 구간을 위해 분할을 바꾸지 않는다 |
| 시점 | 외부 자료는 `as_of` 에 **실제로 이용 가능했던** 것만 (게시 시각이 아닌 가용 시각, P3 수집 계약). 봉 확정 시각 = 마지막 1분 + 1분 (P2-4) |
| 전처리 | 정규화·결측 대체는 학습 구간 안에서만 적합 (C-8) |
| 기록 | 가격 모델 버전·특징 계약 버전·외부 자료 지문·설정 해시를 한 묶음으로 meta 에 (P4-3.3, FR-F3) |

## 3. 판정 기준 (P4-3.2·P4-3.4)

"개선"은 숫자가 조금 좋아진 것이 아니라 우연으로 보기 어려운 차이여야 한다. 최종 평가 구간에서 h 마다:

1. **구간 품질**: 표본별 pinball 손실(분위 3개 평균)의 차이 d = 통합 − 가격 단독. 거래일 단위 블록 부트스트랩(같은 날 표본은 함께 뽑음, 반복·시드는 설정)으로 평균 d 의 95% 구간을 구한다.
2. **보정 유지**: 통합 모델의 10~90% 구간 적중률이 목표(80%)에서 가격 단독보다 더 멀어지지 않는다 (허용 폭은 설정).
3. **방향**: 방향 표시는 통합 모델에도 P2-8 판정(검증 뒤 절반, 최소 호출 수·이항검정·기준선 비교)을 따로 적용한다. 최종 평가 구간 적중률 차이도 같은 블록 부트스트랩으로 구간을 낸다.
4. **여러 h**: 1시간봉 h=1~7 처럼 여러 번 비교하므로 h 들에 Holm 보정을 건다 (프로젝트의 3중 검증과 같은 취지).

| 결과 | 조건 | 화면 표시 |
|---|---|---|
| 개선 확인 | 1의 구간 상한 < 0 (Holm 보정 뒤) 이고 2를 만족 | 통합 결과를 선택지로 제공, "가격 단독보다 나음" |
| 차이 없음 | 1의 구간이 0을 포함 | **검증 부족** — 통합을 기본으로 올리지 않음 (FR-B2) |
| 악화 | 1의 구간 하한 > 0 또는 2 위반 | **검증 부족** + "가격 단독보다 나쁨" |
| 표본 부족 | 교집합 표본·외부 자료가 있는 표본이 최소 수 미만 | **검증 부족** (사유: 표본 부족) |

수치(반복 수, 신뢰 수준, 보정 허용 폭, 최소 표본, 시드)는 `engine/config/default.yaml` 의 `forecast` 아래 새 하위 절에 둔다 (값은 구현 PR 에서 승인).

## 4. P4-2 에 바라는 입력 계약 (초안, hchee99 와 협의)

| 열 | 뜻 |
|---|---|
| `code`, `as_of` | P2 봉과 같은 키. `as_of` 는 KST 시간대 없는 값, 봉 확정 시각 |
| `ext_*` 특징 열 | 숫자만. 이름과 뜻은 P4-2 문서에 |
| `ext_n_docs` | 그 `as_of` 에 이용 가능했던 자료 건수 (예측 카드의 "사용 자료 건수", FR-B3) |
| `ext_last_available_at` | 이용한 자료 중 가장 늦은 가용 시각 (카드 표시·시점 검사용) |
| `ext_missing` | 자료 없음 여부 (P4-2.2). 특징 값은 결측(NaN)으로 두고 0 으로 채우지 않는다 — 모델이 "없음"과 "0건"을 구분하게 |

- 결합 결과의 누락률(P4-2.3)을 종목·월별로 받아 채점 표에 함께 둔다.
- 절단 불변(NFR-4): `as_of` 뒤 가용 시각인 자료를 지워도 그 `as_of` 의 특징·예측이 같아야 한다. P2 의 절단 검사 틀(`test_forecast_model.py`)에 외부 자료 절단을 더한다.

- 1분봉 기간: 2025-03-27 ~ 2026-09, 362거래일 ([`분봉_데이터_설계.md`](분봉_데이터_설계.md) §1).
- OpenDART 공시 목록: 2020-09-01 ~ 2026-10-12, 686,886건, `metadata_only`(보고서명·접수 정보, 원문 없음) — hchee99 수집 보고(10-12). 1분봉 기간을 모두 덮는다. 아직 원본 PC 로 옮기지 않았다.
- 뉴스: 시연 자료가 09-30 ~ 10-02 뿐이라 1분봉 기간과 거의 겹치지 않는다. 통합 모델 학습 입력으로 쓸 수 없다.
- 그래서 첫 통합 모델의 외부 자료는 **공시 목록 특징만**이 현실적이다. 최종 평가 구간(2026-06 이후 약 3.5개월)에 공시가 있는 종목·봉이 적으면 "표본 부족"이 정직한 결과일 수 있다 (기획 ⑩ 위험).
- 가격 단독의 최종 평가 구간 방향 적중률은 sample30 에서 0.49~0.54 (P2-8, §6.4). 통합 모델이 이 기준을 넘는지가 비교의 핵심이다.

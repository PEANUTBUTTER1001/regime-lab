# 구현 전 결정사항

| 항목 | 내용 |
|---|---|
| 문서 목적 | 첫 구현 착수 전에 사용자가 제공해야 할 데이터와 확정해야 할 의사결정을 정리한다. |
| 작성일 | 2026-09-22 |
| 최종 갱신 | 2026-09-22 — 데이터 검토 결과 반영 후, 사용자 결정(미결정 항목 권장안 채택, 승인·보류·제외 항목 확정) 반영. 같은 날 1단계 구현 결과(§2.2), 3단계 HTML/JS 우선 결정(C8), 2·3단계 착수 전 결정 항목(§5.1), Unity 전환 과제(T-8) 추가 |
| 2026-09-23 확인 | E1~E6·E9 확정, E10 잠정(설정 화면 키 입력, T-9 재논의), E7·E8 보류, §2.2의 A2-2·U3-1·V1·V2는 **확인 대기**(잠정값 적용 중). 4단계 착수 전에 확정한다 ([구현_계획 §0.2](구현_계획.md)) |
| 기준 문서 | `SRS.md` v1.1, `design.md`, `기능_정의서.md`, `서비스_기획서.md`, [`데이터_검토_결과.md`](데이터_검토_결과.md), [`구현_계획.md`](구현_계획.md) |
| 상태 | 첫 구현 범위의 결정은 확정됨(§2·§4·§5.1). 잠정 적용 중인 4건(§2.2 A2-2·U3-1·V1·V2)만 확인 대기, E7·E8은 보류, 나머지는 §8 추후 구현 과제로 이관 |

> 표의 `권장안`은 처음 제안한 값이다. **실제 적용 값은 `결정` 열을 따른다.**
> 데이터 기반 결정의 수치·판단 근거는 [`데이터_검토_결과.md`](데이터_검토_결과.md)의 해당 절(§)에 있다. 결정을 바꾸려면 그 문서의 근거를 먼저 확인한다.
> 구현 순서·모듈 구조·완료 기준은 [`구현_계획.md`](구현_계획.md)를 따른다.

**`결정` 열 상태 구분**

| 상태 | 의미 |
|---|---|
| ✅ 확정 | 이 값으로 구현한다. (데이터 검토 또는 사용자 결정) |
| ✅ 확정(조건부) | 확정했지만 적힌 조건을 충족해야 한다. |
| ⏭ 제외·이관 | 이번 구현에서 제외하고 §8 추후 구현 과제로 넘긴다. |
| ⏸ 보류 | 결정 시점을 뒤로 미룬다. 결정 전까지 해당 기능은 구현하지 않는다. |
| ⏳ 확인 대기 | 잠정값을 적용 중이며 사용자 확인이 필요하다. |

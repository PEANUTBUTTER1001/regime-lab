## 1. 개요

### 1.1 목적

본 문서는 다음 기능을 하나의 **과거 데이터 기반 분석 서비스**로 정의한다.

1. 사용자가 선택한 매매 패턴을 코스피·코스닥 종목의 일봉 데이터로 백테스트하고, 시장 국면·시장·시가총액 그룹별로 성과를 분해한다. (R1)
2. 목표 승률과 탐색 범위를 정하면 과거에 그 조건을 충족한 패턴 조합을 찾고(역방향 백테스트), 찾은 조합을 저장·재사용한다. (R2, P1)
3. 사용자가 고른 봉 단위(1분·1시간·3시간·1일 등)로 미래 구간의 통계적 예상 범위를 계산하고, 과거 예측을 실제 결과와 비교한다. (R2, P2)
4. 공시·뉴스 등 외부 자료를 출처와 시각을 보존해 수집하고, 근거 검색(RAG)과 주가 영향력 가중치 분석을 제공한다. (R2, P3)
5. 가격과 외부 자료를 함께 쓴 통합 예측과, 지정 시각에 출처 기반 오프닝 브리핑을 생성한다. (R2, P4)

이 문서는 시스템이 해야 하는 일을 정의한다. 구현 상세는 별도 설계·인수인계 문서에서 관리한다. 모든 화면과 결과는 과거 데이터 분석이며 투자 권유가 아니다. 예측은 과거 데이터로 계산한 통계적 예상 범위이며 실제 가격 전망이나 매매 신호가 아니다.

### 1.2 범위 결정

| 쟁점 | 최종 결정 | 이유 |
|---|---|---|
| 주식 백테스트 시간 단위 | 국내 주식 전략의 신호·진입·청산·성과 계산은 일봉만 사용한다. 분봉 **체결** 백테스트 여부는 D-3에서 정하며, 결정 전에는 포함하지 않는다 | 기존 C-2와 재현성 유지 |
| 1분봉 | 1분봉과 그 집계 봉(1시간·3시간 등)은 **예측·과거 검증**의 입력으로 사용한다 (P2) | 사용자가 고른 봉 단위의 예측 요구 |
| 야간 5분봉 | 야간 선물·환율의 충격 시점 탐지에만 쓰는 v1.1 결정을 유지하되, 데이터 미확보로 이관(T-2) 상태를 유지한다 | 야간 시세 데이터 없음 |
| VWAP 눌림목 | `VWAP_20` 등 전일 확정 기술지표를 이용한 일봉 조건부 분석만 제공한다 | 장중 눌림목 체결 전략은 일봉 전용 제약과 충돌 |
| 조건 탐색 | 정의된 축(패턴 선택, AND/OR, 허용된 패턴 수치, 청산 값)과 허용 값 안에서만 탐색한다. 탐색 구간과 별도 평가 구간을 나누고, 시도 후보 수·3중 검증 결과를 함께 표시한다 (P1, D-1) | 과적합 위험을 드러내고 관리 |
| AI/ML | LLM은 해설·근거 요약·구조화 전략 변환만 수행하며 수치·순위·신호를 결정하지 않는다. 예측·영향력 모델은 엔진에서 학습·평가하며, 결과는 기준선 대비 평가와 함께 통계적 예상 범위로만 표시한다 | 가격 목표·자동 추천 방지 |
| 외부 자료 | 이용·보관 권한이 확인된 출처(D-4)만 수집한다. 게시 시각·수집 시각·이용 가능 시각을 구분해 보존한다. 원문은 권한 범위 안에서만 보관·표시한다 | 데이터 권한·시점 누출 위험 관리 |
| 종목 노출 | 종목 추천 대신, 검증된 과거 조건을 충족한 **분석 대상**과 표본·위험을 표시한다 | 비권유 원칙 준수 |

### 1.3 포함 및 제외

**포함 — R1 (발표 기본 범위, 구현 완료)**

- 코스피·코스닥 일봉 데이터 정제·유니버스 구성, 워밍업 보정
- 핵심 패턴 5종, 일봉 백테스트, 시장/종목 국면 분석
- 비용·체결 제약·미래참조 방지·기간 분할·FDR·무작위 벤치마크 검증
- 실행 API(`run_id`), Web UI(전략 빌더·진행·결과·종목 상세·AI 보고서·설정), LLM 보고서와 숫자 대조

**포함 — R2 (확장 범위, 2026-10-20까지)**

- P1 역방향 백테스트(조건 조합 탐색), 패턴 수치 파라미터화, 찾은 조합 저장·불러오기
- P2 1분봉 실사·정규화·시간봉 집계, 봉 단위 예측 모델·과거 as_of 예측·채점 지표·회색 예측 화면
- P3 외부 자료(OpenDART 공시 소급·순방향, 뉴스 순방향 수집) 수집·출처 대장·시각 규칙, RAG 보관·검색, 영향력 가중치 학습, 자료 보관함·영향 분석 화면
- P4 가격·자료 특징 결합, 통합 모델과 가격 단독 비교, 통합 예측 화면, 브리핑 스냅샷·LLM 브리핑·지정 시각 자동 실행·브리핑 화면
- 추가 작업: 후순위 패턴 5종(X6), 로그인·배포·다중 사용자(X3), 시세 데이터 갱신 경로(X4), 과거 지수 확보·국면 재계산(X5), LLM 공급사 추가(X7), 실행 기록 목록(X2), UI/UX 개선(X1), 접근성 개선(X10), 원본 데이터 팀 공유(F1)

**보류**

**제외**

### 1.4 R1 발표 기본 범위 (고정)

R2를 구현해도 다음 R1의 의미는 바꾸지 않는다. 바꿔야 하면 이 문서를 다시 개정한다.

- 체결 규칙(FR-E1~E5), 비용(FR-E4), 워밍업 중 거래 금지(FR-E8)
- 승률 정의: 집계 포함 거래 중 비용 차감 후 `net_ret > 0` 비율. 기준일 보유 중이라 제외된 거래는 분모에 넣지 않는다
- 3중 검증 기준: 기간 분할(V1), 무작위 벤치마크 95 백분위(V2), BH-FDR q ≤ 0.10 (FR-A3~A5)
- 국면 판정(FR-D5)과 유니버스 규칙(FR-D4, U3-1 한계 포함)
- 실행 결과 형식(`runs/<run_id>/`)과 실행 API 계약(FR-X2\~X6), LLM 숫자 대조·권유 표현 차단(FR-L2~L4), 비권유 고지(FR-U7)

### 1.5 용어

| 용어 | 정의 |
|---|---|
| 패턴 | 일별 매수 조건. 기본 수치는 설정 파일에 있고, 조합별 수치는 허용 범위 안에서 지정한다(FR-R7). 예: RSI(14)가 30을 상향 돌파 |
| 전략 | 패턴 조합(AND/OR), 청산 규칙, 대상·기간으로 구성된 실행 단위 |
| 역방향 백테스트 | 목표 승률과 탐색 범위를 정하면 후보 조합을 생성·백테스트해 목표를 충족한 과거 조합을 찾는 기능 |
| 탐색 구간·평가 구간 | 후보를 고르는 데 쓴 기간과, 고른 후보를 다시 확인하는 별도 기간. 평가 구간은 재탐색에 쓰지 않는다 |
| 봉 단위 | 예측·검증에 쓰는 시간 단위(1분·1시간·3시간·1일 등) |
| as_of | 예측을 만든 기준 시점. 그 시점까지 확정·이용 가능한 입력만 쓴다 |
| 예상 범위 | 예측 결과의 화면 표현. 회색 구간과 방향으로만 표시한다(E17) |
| 외부 자료 | 공시·뉴스 등 가격 외 자료. 게시 시각·수집 시각·이용 가능 시각을 구분한다 |
| 영향력 가중치 | 자료 유형·주제와 이후 가격 움직임의 관련성을 학습한 값. 인과 추정이 아니다 |
| RAG | 질문·브리핑에 맞는 과거 근거 자료를 출처와 함께 찾아 주는 검색 |
| 브리핑 스냅샷 | 지정 시각에 수집을 마감하고 고정한 입력 묶음. 같은 스냅샷이면 같은 근거의 브리핑이 나온다 |
| 국면 | 200일선 위치와 20일 기울기로 판정한 상승(bull)·횡보(sideways)·하락(bear) 상태 |
| 분석 대상 | 검증을 통과한 과거 조건에 부합하는 종목. 추천·매매 지시가 아님 |
| 미래참조 | 기준일(as_of) 이후 정보를 신호·국면·예측·결과에 사용하는 오류. 절대 금지 |
| 워밍업 | 지표 계산을 위해 백테스트 전 확보하는 최소 250거래일 구간 |

### 2.2 운영 환경

- Python 3.12, pandas, numpy, pyarrow 및 웹 UI 런타임을 사용한다. (`pandas-ta`는 호환 확인 후 사용하며, 비호환 시 지표를 직접 구현해 `test_indicators`로 검증한다.) 새 라이브러리·서비스는 `AGENTS.md` §9에 따라 먼저 승인받는다.
- 개발·시연은 메모리 8GB 이상의 개인 노트북에서 수행한다. 로그인·배포·다중 사용자 환경(X3)의 호스팅·HTTPS·보안 범위는 X3.1에서 확정한다.
- 원본 시세, 1분봉, 외부 자료 원문은 저장소에 커밋하지 않는다. 저장소는 공개 상태다.
- LLM API 키는 환경변수 또는 설정 화면 입력(서버 메모리 보관, 재시작 시 소멸)으로 주입한다(E10 잠정, T-9 재논의). 키는 파일·브라우저 저장소·로그·응답에 남기지 않는다.

### 3.10 봉 예측·과거 검증 (FR-F, P2)

세부 값(예측 봉 개수, 필수 출력, 지원 봉 목록)은 D-2에서 정하되, 화면 표시는 E17(구간·방향)을 따른다. 근거: [`plan/02-multiframe-forecast.md`](plan/02-multiframe-forecast.md)

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-F1 | 1분봉 원본을 읽기 전용으로 실사(위치·스키마·시간대·세션·누락·수정주가)하고, 세션 경계·중복·결측을 정규화한다. 1시간·3시간 등 집계 봉은 대표 사례의 수기 계산과 일치해야 한다. 품질이 모자라면 해당 봉 단위는 지원하지 않는다. | M |

| FR-F3 | 각 예측은 봉 단위, 마지막 확정 입력 봉, `as_of`, 모델 버전, 데이터 지문을 기록한다. 미완성 현재 봉은 입력으로 쓰지 않는다. | M |

| 브리핑 스냅샷·결과 | 출력 | 기준 시각, 입력 스냅샷 버전, 근거 목록(출처·시각), 본문, 상태 |
| 실행 작업 API | 입출력 | 실행 요청·`run_id`·상태·진행률·취소·결과·오류 코드 |
| 분석 API/UI | 출력 | 전략 결과, 탐색 결과, 예측, 자료 검색, 브리핑, 고지 및 실패 사유 |

외부 서비스는 KRX/FinanceDataReader, 허가된 LLM API(OpenAI·Gemini·Anthropic), D-4에서 허가된 외부 자료 출처(OpenDART, 뉴스 RSS·검색 등)를 사용한다. 각 출처의 이용 조건·호출 한도·보관 범위를 지키며, 새 외부 서비스는 사용 전에 승인받는다.

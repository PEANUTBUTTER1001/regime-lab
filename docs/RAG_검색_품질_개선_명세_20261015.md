## 5. A안의 구현 가능한 요구사항 — 조사 지원 SRS 승인 반영

| ID | 요구사항·판정 규칙 |
|---|---|
| SQ-1 정규화 | 질의·대상 필드 모두 Unicode NFKC와 영문 소문자 적용. 현행 지원 문자 범위인 한글 음절·ASCII 영문·숫자 유지, 구두점은 구분자 취급. 외부 형태소 분석·별칭·동의어 확장 없음 |
| SQ-2 질의 단위 | 공백·구두점으로 구분한 각 연속 한글/영문/숫자 덩어리를 조건으로 유지. `대한전선`은 완전한 한 조건, `삼성전자 자사주 매입 화성기지`는 네 조건, `없는회사검증ZXQ987`는 혼합 전체가 한 조건. 원형 OR 허용 조사 변형은 같은 조건의 대안이며 조건 삭제 아님. 2-gram의 존재를 조건 충족으로 대체 금지 |
| SQ-3 완전 일치 | 각 조건의 전체 문자열 또는 허용 조사 변형이 같은 문서의 title 또는 corp_name 한 필드 안에서 이어져야 충족. 조건끼리는 서로 다른 허용 필드에 있어도 가능. 한 조건을 두 필드·두 문서에서 조립 금지. 한글 또는 한글/ASCII 경계의 공백 차이는 허용하되 별개의 ASCII 영숫자 토큰을 연결하지 않음. ASCII로 시작·끝나는 조건은 해당 끝에서 더 긴 ASCII 영숫자 토큰의 부분 문자열과 일치 금지. 조사 분리 대안은 기본어의 독립 단어 경계까지 확인 |
| SQ-4 구체 경계 | `대한전선`↔`대한 전선`, `자사주매입`↔`자사주 매입`, `HBM3E`↔`hbm3e양산`, `2분기`↔`2 분기` 허용. `HBM3E`↔`HBM3E2`, `987`↔`98`·`1987`, `화성기지`↔`화성 사업 기지`, `자사주매입`↔`자사주 계획물량 매입` 불허. 글자 순서·연속성 보존 |
| SQ-5 모두 충족 | 각 문서는 모든 질의 단위를 충족해야 반환 자격 획득. 하나라도 미충족이면 대표·similar에서 모두 제외. 후보가 없으면 기존 no_evidence와 빈 items 사용. 부분 일치 결과로 자동 완화 금지. 구분자만 있는 질의도 조건 0개로 전체 문서를 허용하지 않고 no_evidence |
| SQ-6 점수용 토큰 | 자격 판정과 별도로 점수용 토큰화 수행. 최대 한글 연속 구간에만 기존 2-gram 적용, 최대 ASCII 영숫자 연속 구간은 통째로 유지. `없는회사검증ZXQ987` → 한글 2-gram + `zxq987`; `HBM3E양산` → `hbm3e`, `양산`; `2분기` → `2`, `분기`. 혼합 덩어리에서 zx·xq·q9·98·87 생성 금지. 영문/숫자는 같은 연속 식별자 안에서 다시 분리하지 않음. 기본어 토큰은 원래 질의 토큰에 포함되므로 별칭·새 단어를 점수 질의에 추가하지 않음 |
| SQ-7 순서·통계 | 기존 as_of 버전 선택·명시 종목 필터로 보이는 문서 집합 V를 먼저 구성. BM25 N·df·평균 길이는 기존처럼 V만 사용. 완전 조건 집합 E는 V의 부분집합으로 별도 계산하고, 점수 결과 중 E에 속한 후보만 정렬·후보 수 제한·묶기/MMR에 전달. 상위 100건을 먼저 자른 뒤 완전 조건을 검사해 뒤의 유효 후보를 잃는 처리 금지 |
| SQ-8 표시 의미 | matched_tokens는 여전히 점수에 실제 기여한 토큰이며 의미적 조건 충족 설명으로 확대하지 않음. 회사명 전체 문자열의 존재는 해당 회사의 확정 종목 연결·본문 사실·매입 실행의 증명 아님. 의미 분석·부정문 판정 없음 |
| SQ-9 호환 | 기존 API 필드·오류 형식·CLI 인자·수집 스키마 유지. 검색 의미는 부분 OR에서 조건 단위 AND로 변경되는 승인 대상. INDEX_VERSION 2→3으로 이전 토큰 색인과 분리. 가중치·min_score·group_threshold 등 수치 변경 없음 |

조사 포기 제안은 사용자 정정으로 철회. 원형 보존에 더해 `이/가·은/는·을/를·과/와`를 받침 규칙에 맞을 때 1회 분리. 설정 `rag.query_particles`로 목록, `rag.particle_min_base_chars: 2`로 최소 기본어 길이 관리. 분리 기본어는 문서의 독립 단어 또는 허용 조사 결합 형태로 확인. `삼성전자가→삼성전자`, `대한전선은→대한전선`, `SK하이닉스가→SK하이닉스` 허용. `국가→국`, `전문가→전문`, `대한전선→한전` 불허. 영문·숫자로 끝나는 식별자는 조사 분리 대상 아님. 재귀 분리·복합 조사 해석·명사의 완전한 형태소 판별은 지원하지 않음.

기존 `ev.formSub`의 조사 검색 안내 유지. 초기의 “조사가 붙지 않은 명칭을 입력” 문구 제안은 폐기. 이번 구현에서 웹 파일·새 API 필드 변경 없음.

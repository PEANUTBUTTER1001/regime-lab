# 외부 자료·영향력 가중치 일봉 예측 — 승인 요구사항

승인: 2026-10-16, 사용자 “영향력 학습·가중치 결합까지 포함”, 상세 SRS 제시 후 “권장안으로 진행 $execute”.
기준: SRS FR-N6·N7, FR-B1~B3, 결정 P4-3a·P3-12a·P3-12b·P3-10. 담당 배정 변경 없음.

## 1. 작업 개요

가격 단독 A, 가격+자료 개수·유형 B, B+과거 학습 가중 특징 C를 같은 일봉·1~5거래일·표본·분할로 비교.
P4-3a v1은 보존하고 가중치 결합을 후속 확장. 성능 개선은 구현 완료와 별도 판정.

## 2. 구현 범위

### 포함

종목·기간·수집 범위 점검, 자료 특징, Ridge 영향력 학습, 시간 순서 가중 특징, A/B/C 비교,
입력 문서 버전·가중치 추적, 기존 예측 화면 선택·근거 보기, 서버 CLI, 호환성·합성/회귀 검증.

### 제외

뉴스 소급·신규 출처/의존성·임베딩·벡터 DB·LLM 수치 예측·유사 사례 실현 결과 검색 모델·분봉 제품화·
웹 학습 실행·원문/LLM 전송 확대·기존 확정 분할/가격 파라미터 변경·성능 향상 보장.

## 3. 기능 요구사항

1. FR-01: 승인 출처·metadata_only·종목 연결·기간 교집합·coverage·버전·시각을 점검. 미연결·제외 사유,
   구간별 사건/거래일·누락률 기록. 빈 자료를 학습 성공으로 저장하지 않음.
2. FR-02: observed는 first_seen_at/available_at, historical_assumed는 승인 소급 정책. 일봉 시작 > 이용 가능 시각.
   장후/휴장일은 다음 실제 거래일. 날짜뿐인 소급 공시는 일봉만. 같은 문서의 당시 버전 하나만.
3. FR-03: 순수 doc_features(docs,bars,cfg,mode). code/as_of/f_*/docs_missing. 창1·5·20거래일,
   전체·출처 유형·공시 유형 건수. report_base/제목 설정 규칙 첫 일치, 기타 포함. 버전/중복 중복 계수 금지.
   확인된 정상0건과 공백/unknown/결합 실패의 결측 구분.
4. FR-04: Ridge 입력은 기존 가격 특징+자료 특징, 목표 log(close(t+h)/close(t)), h1~5 각각.
   동일 Ridge 가격 단독 대비 RMSE/MAE. 학습 구간만으로 결측 처리·표준화, 계수는 원래 입력 단위 환산.
   alpha 후보0.1/1/10 내부 시간 검증, 고유 학습 사건30 미만 계수 적용 제외. 거래일 묶음 bootstrap1000,
   95% 구간과 근거 저장. 최종 평가로 특징/가중치/alpha 선택 금지. 관련성만 표현.
5. FR-05: 최소252거래일 후 다음63거래일 단위 expanding 학습. 목표 실현이 적용 경계를 넘으면 제외.
   행보다 앞선 정보로 만든 가중치만 입력. 초기 이력 부족은 influence_missing.
   외부 valid/test는 outer train 종료까지 튜닝·학습 완료한 가중치로 고정. knowledge_cutoff는 사용 정보 최종 시각.
   사후 재현 실험과 실제 생성 시각 구분. 평가 n_eval/sample_ok를 같은 평가 입력 선택에 재사용 금지.
6. FR-06: 가중 특징=유형·창별 건수×적격 계수. 원자료 특징 유지, influence_missing 별도.
   BM25 직접 가산 금지. 보조 Ridge 기여는 최종 HGB의 설명/인과와 구분.
7. FR-07: A/B/C 공통 실현 표본. min1000행/20일, pinball 상대개선0.005, bootstrap1000,
   alpha0.05, 목표 coverage0.80 이탈의 비교대상 대비 악화 허용0.02. B-A/C-A/C-B×h 전체 Holm.
   C의 추가 효과는 A/B 모두 개선된 h만. 기존 v1 결과 재판정 없음. 개선 없음/부족은 검증 부족.
   기본은 A, 평가로 자동 전환 없음.
8. FR-08: 전체 적격 자료로 집계, 검색 top-k는 근거 정렬만. 문서/버전/봉/유형/창/계수 버전·입력 지문 추적.
   뉴스 갱신이 OpenDART 접근을 지우지 않음. 현재 삭제·만료·권한 제한 준수. 과거 예측 덮어쓰기 없음.
9. FR-09: 서버 CLI influence-run, forecast-run --with-docs [--docs-mode ...] [--with-influence].
   가중 옵션만 단독 사용은 오류. 웹은 조회만. A/B/C·h별 판정·누락·버전·소급 가정·회색구간·고지 표시.

## 4. 입력·출력 및 인터페이스

- 입력: 확정 Parquet·manifest·coverage·가격·설정·호출자 시각. 엔진/API가 ingest를 import하지 않음.
- 영향력 형식2: 기존 세 파일, 가중치에 h/window/feature, meta에 knowledge_cutoff·전처리·분류·학습 정보.
  형식1 조회 유지, cutoff 증거 없는 형식1은 예측 입력 제외.
- 예측 형식5: 기존 세 파일+evidence.parquet(문서 참조·버전·종목·연결 봉·유형·유효 구간, 원문 없음).
  fusion_kind none/docs/weighted, 비교 실행 연결, 가중치 버전·설정 지문. 형식2~4 조회 유지.
- API: 기존 경로/필드 유지. 영향력 h 선택(기본1). 예측 근거 GET /api/forecasts/runs/{run_id}/evidence?code=&as_of=&page=&page_size=.
  해당 문서 버전 없음은 missing, 다른 버전으로 대체 금지. 상세는 기존 자료 조회.
- CLI: 기존 가격 명령 유지. 학습 API 추가 없음.

## 5. 예외 및 경계 상황

미연결/기간 없음은 사유 기록. unknown coverage는 정상0건 아님. 적격 가중치 없음을 자료 결합으로 조용히 대체 금지.
동일 문서·버전 내용 충돌은 오류. 희소/불안정은 명시. 미래 추가로 과거 입력 변경 금지.
삭제·만료는 표시 제한 및 재현 제한 사유. 미완성 결과 비공개·같은 이름 덮어쓰기 거부.
개선 없음은 not_improved, 부족은 insufficient.

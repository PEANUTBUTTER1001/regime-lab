| 항목 | 값 |

## 1. 전략 빌더 — 새 패턴·선택 청산 (약 1분)

1. 사이드바 **전략 빌더**. 매수 패턴 14종 중 **52주 신고가 돌파**·**볼린저 수축 돌파**, 결합 **OR**
2. 매도: 손절 −8%, 익절 +20%, 최대 보유 **10일**, **트레일링 스톱 −10%** 사용
3. **백테스트 실행** → 약 1초 뒤 결과

확인한 결과(sample30): 거래 **231** · 승률 **52.4%** · 지수 대비 평균 초과 **+1.98%p** · FDR 통과 · 무작위 99.5백분위 · 기간 분할 "표본 부족"

## 2. 결과 — 3중 검증과 청산 사유 (약 1분)

- 위 카드 3개: 기간 분할 / 거짓 발견 통제(BH) / 무작위 벤치마크
- 요약 아래 **청산 사유**: 최대 보유 115 · 손절 61 · 익절 32 · **트레일링 스톱 22** · 상장폐지 1 → 새 매도 조건이 실제로 작동한 횟수
- 말할 점: "승률만이 아니라 같은 기간 무작위 진입과 비교하고, 기간을 나눠 다시 본다"

## 3. 역방향 탐색 — 목표 승률로 조건 찾기 (약 2분)

1. 사이드바 **역방향 탐색**. 목표 승률 **42%**, 최소 거래 **30**
2. 패턴: **52주 신고가 돌파·MACD 골든크로스·볼린저 수축 돌파·거래량 동반 돌파** (기본 5종 체크는 해제)
3. 최대 보유 **10·20일**만 선택 → 미리보기 **후보 52개** (PR #50 뒤 예상 약 5초)
4. 실행 → 약 3초 뒤 결과

확인한 결과: 두 구간 모두 충족 **15** · 탐색 구간만 10 · 미충족·거래 부족 27.
1위 **c015 = 볼린저 수축 돌파 OR 52주 신고가 돌파, 10일**: 탐색 구간(~2024-02-29) **130건 52.3%** → 평가 구간(2024-03-01~) **101건 55.4%**

- 말할 점: "탐색에 쓰지 않은 뒤 기간에서도 목표를 넘는지 다시 확인한다. 순위는 추천이 아니다"
- **주의:** 패턴 14종을 모두 체크하면 후보가 6만 개를 넘어 상한(200)에 막힌다 — 3~4종만 고른다

## 4. 조합 저장 → 빌더로 불러오기 (약 30초)

1. 결과 표 c015 행 **선택** → 아래 저장 칸 이름(예: "52주 신고가 OR 볼린저 수축 10일") → 저장
2. 사이드바 **저장한 조합** → 방금 저장한 조합(출처: 탐색 기록 c015 · 두 구간 모두 충족) → **빌더로 불러오기**

## 5. 자료 보관함 (ext_store 가 있을 때, 약 1분)

1. 사이드바 **자료 보관함**. 기준 시각을 바꾸면 그때 이미 쓸 수 있던 자료만 보인다(미래 자료·버전 숨김)
2. 상태 버튼(정정 공시·버전 변경·종목 미연결)과 **기간 안 수집 상태**(완료·순방향·부분·공백) — 공백은 "0건"과 다르다
3. 정정 공시 행 → **자료 상세**: 버전 이력, 정정 관계는 "후보"로만, 원문 대신 출처 링크

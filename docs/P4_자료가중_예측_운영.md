# 자료·가중치 결합 일봉 예측 — 서버 실행·검증

기준: 2026-10-16 승인 [요구사항](P4_자료가중_예측_요구사항.md). 서버 PC에서만 원본/소급 공시를 준비하고 실행.
팀원 PC는 서버 웹에서 결과 조회. 실제 접속 주소·키·원문을 이 문서나 Git에 기록하지 않음.

## 1. 실행 전 확인

1. 서버 저장소에 이번 구현 반영. 실행 중인 서버의 재시작은 운영자가 승인한 시점에만 수행.
2. 기존 `uv sync --project engine`, `uv sync --project api`, `uv sync --project ingest` 환경 사용. 신규 의존성 없음.
3. `engine/config/paths.local.yaml`의 `store`는 KRX 원주가 일봉/종목 master, `ext_store`는 **OpenDART 공시의 docs와 coverage를 함께 가진 폴더**.
   `runs`는 파생 결과 저장 위치. 원본·기존 결과 덮어쓰기 없음.
4. `ext_store/docs/source=opendart/_manifest.json`: schema_version1, license_scope=metadata_only, 비활성 출처 아님.
   `coverage/source=opendart/coverage_log.parquet`에는 Y/K 시장의 수집 상태·관측 시각 이력이 필요.
   출처 대장/보관 허용 범위 확인은 운영 데이터 승인 담당의 선행 작업. 뉴스 출처를 OpenDART로 바꾸어 우회 금지.
5. `tickers[].code`가 가격 종목 코드에 연결되어야 함. 회사명 유사도만으로 종목을 임의 연결하지 않음.
6. 학습 종료2024-02-29 / 검증 종료2025-02-28 / 이후 test를 유지. 최근 뉴스만 있으면 과거 학습 교집합이 생기지 않음.
   기존 P3-7.4 OpenDART 5년 소급을 먼저 확보. 과거 뉴스 소급은 제외(P3-10).
7. 수집/소급 명령·키·권한·장애 복구는 기존 `ingest/README.md`, `docs/P3_수집_계약.md` 적용.
   이 작업이 수집을 대신 실행하거나 원본 DB를 수정하지 않음.

## 2. 가격·자료 기본 결합만 확인

실제 관측 이력이 학습 기간에 존재하는 경우:

```powershell
uv run --project engine regime-lab forecast-run --timeframe 1d --with-docs --docs-mode observed --sample
```

소급 OpenDART를 사용하는 경우:

```powershell
uv run --project engine regime-lab forecast-run --timeframe 1d --with-docs --docs-mode historical_assumed --sample
```

- 같은 가격·종목·분할의 A(가격)와 B(자료 특징) 두 실행 생성.
- 창1/5/20거래일의 전체/유형 건수, 자료 누락률, 당시 문서 버전·연결 봉·입력 지문 저장.
- 최소 학습 자료 교집합이 없으면 비정상 성공 대신 오류. unknown/공백은 정상0건으로 채우지 않음.
- `--sample`은 기존 sample30 파일이 필요. 표본 부족이면 대상 확대 전 원인부터 확인.

## 3. 영향력 학습 후 A/B/C 생성

소급 공시 기준의 빠른 확인 순서:

```powershell
uv run --project engine regime-lab influence-run --as-of-mode historical_assumed --sample
uv run --project engine regime-lab forecast-run --timeframe 1d --with-docs --docs-mode historical_assumed --with-influence --sample
```

순방향 관측 자료가 실제 학습 구간을 충족하는 경우 두 명령의 모드를 모두 `observed`로 변경.
전체 종목 실행은 두 명령에서 모두 `--sample` 제거.

**두 명령의 입력 데이터·설정·종목·모드가 같아야 함.** 데이터/설정/종목이 달라지면 영향력 학습부터 재실행.
예측 명령이 적격 모델을 찾지 못하면 실패하며, B를 C로 이름만 바꾸어 제공하지 않음.

학습은 가격 특징을 통제한 Ridge, 목표는 h1~5 누적 로그수익률. 최소252거래일 후63거래일 단위
시간 순서 가중치를 만들며, 최종 외부 valid/test에는 train 끝까지 완료한 계수를 고정.
alpha0.1/1/10은 내부 시간 구간에서 선택. 첫 내부 holdout 이력이 부족한 구간은 가운데 후보1.0 사용.
고유 학습 사건30 미만 유형은 독립 계수 적용 제외. 계수95% 구간은 학습 거래일 bootstrap1000 기준.
최종 평가의 표본/성적/표시 플래그는 같은 평가 구간의 입력 선택에 재사용하지 않음.

## 4. 결과 파일

| 위치 | 내용 |
|---|---|
| `runs/influence/<model_version>/meta.json` | 형식2, h별 계수 snapshot·전처리·alpha·적용 구간·knowledge_cutoff·평가·입력 지문 |
| 같은 폴더 `weights.parquet` | h/유형/창/계수·학습 사건 수·평가 사건 수·불확실성·표본 상태 |
| 같은 폴더 `events.parquet` | 자료 버전·종목·연결 봉·train/valid/test. 최종 HGB의 문서 기여를 주장하지 않으므로 contribution은 null |
| `runs/forecasts/<run_id>/meta.json` | 형식5, none/docs/weighted, 비교 A/B 연결, 자료·가중치 버전·누락률·지문 |
| 같은 폴더 `predictions.parquet`, `scores.json` | 기존 예상 구간/방향 및 같은 표본의 모델 비교 |
| 자료 결합 폴더 `evidence.parquet` | 실제 입력 문서의 식별자·버전·봉·유형·유효 구간. 기사 원문·본문 없음 |

임시 폴더 쓰기 완료 후 공개. 기존 이름 덮어쓰기 거부. 과거 예측 형식2~4·영향력 형식1 조회 유지.
형식1 가중치는 knowledge_cutoff·시간 순서 snapshot 증거가 없어 C 입력에 사용하지 않음.

## 5. 웹 확인

1. 서버 웹의 봉 예측 진입. 기본 선택 A 유지.
2. 예측 실행 목록에서 A/B/C 구분 확인. 비교 링크로 같은 종목·기준 시각의 A/B 이동.
3. 회색 예상 범위·방향·상승 확률·실제 종가, h별 평가 판정 확인.
4. 자료 건수·train/valid/test 누락률·가중치 버전·실제 수집/소급 가정·과거 재현 실험 표시 확인.
5. 근거 목록의 문서 버전·출처·이용 가능 시각·집계 창 확인. 검색 top-k를 자료 건수로 해석하지 않음.
6. 최신 버전이 아닌 저장된 버전을 찾지 못하면 missing. 삭제/만료 자료는 제목·URL 표시 제한.
   원래 예측은 그대로 유지. 원문 상세의 현행 표시 제한은 기존 보관함 계약 적용.
7. 영향 분석의 h 선택으로 h별 계수·집계 창·평가·표본 부족 확인. Ridge 계수는 최종 HGB의 기여도와 구분.
8. 뉴스 자동 갱신 후 공시·뉴스 출처가 함께 조회되는지 확인. 같은 뉴스 출처의 옛 snapshot 전체를 계속 합치지 않음.
9. 한국어/영어·다크 모드·좁은 화면, 브라우저 콘솔 오류 확인.

## 6. 개선 판정

공통 평가1000행·20일 이상, pinball 상대개선0.5% 이상, 거래일 bootstrap1000·Holm alpha0.05,
목표 coverage80% 이탈의 비교대상 대비 악화2%p 이하. 확장 실행은 B-A/C-A/C-B×h 전체를 함께 보정.
C의 추가 효과는 A/B 모두 개선된 h만. 미개선·부족은 검증 부족. 기본 모델 자동 교체 없음.

자료 건수나 학습 성공은 성능 개선의 증거가 아님. 소급 가정 결과는 당시 실제 보유/발행 성과와 별도 보고.

## 7. 오류와 다음 조치

| 메시지/상태 | 확인 |
|---|---|
| metadata_only manifest 필요 | ext_store가 공시 docs/manifest/coverage의 올바른 루트인지, 출처·권한·활성 확인 |
| 외부 자료 학습 교집합 없음 | 종목 연결·2024 이전 공시·Y/K coverage·시점 모드 확인 |
| 영향력 학습 표본 부족 | 적격 학습252일·유형별 고유 사건30·수집 공백 확인 |
| 동일 입력 영향력 모델 없음 | 두 명령의 모드·sample·설정·가격/자료 버전 일치 후 influence-run 재실행 |
| 검증 부족 | 표본/기간/효과/유의성/coverage 확인. 임계값을 낮춰 성공으로 바꾸지 않음 |
| 근거 missing/restricted | 당시 버전 접근 경로·현재 삭제/만료/권한 확인. 다른 버전으로 대체 금지 |

## 8. 운영 수용 기록

2026-10-16 로컬 합성 검사와 서버 실데이터 수용은 별도. 실제 서버에서 위 명령·새 결과·조회·출처 보존·
평가를 수행하기 전 실데이터 학습/개선 완료로 판정하지 않음. 학습 시간·최대 메모리·결과 크기·조회 지연은
실제 데이터 규모와 함께 기록. 서버 재시작·실제 수집·배포는 이 문서 작성만으로 실행되지 않음.

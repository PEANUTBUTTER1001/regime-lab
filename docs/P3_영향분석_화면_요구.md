## 1. 화면이 받아야 할 입력

### A. 모델 정보 (모든 응답 공통)

| 필드 | 뜻 | 화면 사용 |
|---|---|---|
| `model_version` | 학습 결과 식별자 | 표·차트 머리에 항상 표시 |
| `target` | 무엇과의 관련성인지 (예: 다음 1거래일 지수 대비 초과수익, 다음 N봉 수익률) | 제목 아래 설명 |
| `as_of_mode` | 학습 입력 문서 선택 기준 (`observed` / `historical_assumed`) | 표시. historical_assumed 는 "소급 가정" 안내 |
| `periods.train` · `periods.valid` · `periods.test` | 학습·검증·최종 평가 기간 (시간 순서) | 차트 배경에 구간 표시, 표의 평가 기간 |
| `baseline` | 비교 기준선 이름과 지표 값 (예: 가격만 쓴 기준선) | 가중치 표 위 "기준선 대비" 한 줄 |
| `min_eval_samples` | 표본 부족 판정 기준 (P3-12 가 정함) | 표본 부족 표시 기준 설명 |

### B. 가중치 표 (행 = 자료 묶음)

| 필드 | 뜻 |
|---|---|
| `group_type` | 묶는 기준: `source_type`(공시·뉴스) · `report_type`(공시 유형) · `topic` 등 |
| `group` | 묶음 이름 |
| `weight` | 학습된 가중치 또는 기여도 |
| `direction` | `+` / `-` / `0` (불안정하면 `0`) |
| `n_events` · `n_eval` | 학습에 쓴 사건 수 · 최종 평가 구간 사건 수 |
| `eval_metric` | 최종 평가 구간 지표 (기준선과 같은 지표) |
| `ci_low` · `ci_high` | 불확실성 구간 |
| `sample_ok` | `n_eval ≥ min_eval_samples` 이고 구간이 정의됐는지 |

### C. 사건 표시 (종목·기간 조회, 가격 차트 위 표시)

| 필드 | 뜻 |
|---|---|
| `doc_id` · `version` | 자료와 그 시점 버전 (보관함 상세로 연결) |
| `ticker` | 연결 종목 |
| `available_at` | 자료를 쓸 수 있게 된 시각 (offset 포함 ISO) |
| `linked_bar_start` | 연결된 첫 봉 시작 시각 — 아래 §2 규칙 |
| `group` | 가중치 표의 어느 묶음인지 |
| `contribution` | 그 사건의 기여도 (없으면 null) |
| `period` | 이 사건이 학습·검증·평가 중 어느 구간인지 (표본 안·밖 구분) |

가격은 새로 받지 않고 기존 종목 상세(`/api/runs/{run_id}/stocks/{ticker}`)의 일봉, 또는 P2 봉 데이터를 쓴다.

## 2. 시간 순서 규칙 (미래 정보 금지)

1. **문서 선택:** 기준 시각 T 에 보이는 버전만 — 근거 검색·보관함과 같은 `select_as_of` 규칙 (observed: `first_seen_at ≤ T` 이고 `available_at ≤ T`).
2. **봉 연결:** 첫 봉은 `bar.start > available_at` (수집 계약 §4-5). 봉 시각은 시간대 없는 KST 이므로 문서 시각은
   `bars.to_kst_naive` 로 바꿔 비교한다. 정확히 09:00 에 관측된 자료는 09:00 봉이 아니라 다음 봉.
3. **일봉 연결:** 장 마감 뒤·휴장일 자료는 가격 데이터 날짜 기준 **다음 실제 거래일** 첫 봉. 평일 규칙으로 추정하지 않는다.
   날짜만 있는 소급 공시는 일봉 연결에만 쓴다(분봉 금지).
4. **표본 안·밖:** 학습 구간 사건에 그 구간으로 학습한 모델의 기여도를 겹쳐 그리면 표본 안 값이다. 화면은 사건마다
   `period` 를 보이고, 결론 문구는 최종 평가(test) 구간 값만 쓴다.
5. **as_of 를 바꾸면** 그 시각까지 학습이 끝난 모델 버전만 고른다(`periods.train` 끝 ≤ T). 그런 모델이 없으면 결과 없음(§4).
6. **절단 불변:** T 뒤의 자료·가격을 지워도 T 시점 화면(사건 목록·연결 봉·선택된 모델·표)은 같아야 한다.

## 3. 표본 부족의 의미

- `sample_ok = false`: 가중치·방향을 **결론으로 강조하지 않는다** — 회색 처리, "표본 부족" 표시, 방향 화살표 숨김.
- 불확실성 구간이 0 을 포함하면 방향을 "불확실"로 보인다 (FR-N7 "표본이 부족한 가중치는 결론으로 강조하지 않는다").
- 기준선보다 평가 지표가 낫지 않으면 표 위에 "기준선 대비 개선 없음"을 먼저 보인다 — 개선이 없으면 통합 예측에 강제 적용하지 않는다(plan/03 작업 ⑨).

## 4. 결과 없음의 종류 (서로 다른 이유로 구분해 보인다)

| 상황 | 뜻 | 화면 |
|---|---|---|
| 모델 없음 | P3-12 결과가 아직 없거나 T 까지 학습이 끝난 버전이 없음 | "학습 결과 없음" + 이유 |
| 사건 없음 | 모델은 있으나 그 종목·기간에 T 시점 보이는 사건이 0건 | "이 기간 연결된 자료 없음" |
| 수집 공백 | 그 기간 수집 범위가 `gap`·`partial` (보관함 수집 상태와 같은 근거) | "수집 공백 때문에 0건일 수 있음" + 보관함 링크 |
| 자료 없음 | ext_store·모델 파일을 읽을 수 없음 | 기존 `data_unavailable` 오류 화면 |

"0건"과 "수집 실패"를 같은 빈 화면으로 보이지 않는다 (FR-N4).

## 5. 표시 원칙

- 모든 수치는 **관련성**이며 인과·미래 수익 보장이 아니라는 고정 문구를 표 위에 둔다(FR-N6).
- 원문을 보여 줄 수 없는 자료는 제목·출처 링크만 (보관함과 같은 `license_scope` 규칙).
- 계산은 엔진, 웹은 API 결과 표시만(FR-X6).

## 6. 구현할 때 확인할 테스트 (계약 승인 뒤)

- 절단 불변: T 뒤 자료·가격·모델 버전을 지워도 T 화면 응답이 같다.
- 시각 경계: 09:00 정확 관측·장 마감 뒤·휴장일·UTC 시각 문서의 연결 봉.
- 표본 부족·불확실 표시, 결과 없음 4종이 서로 다른 응답으로 나온다.
- 모델 버전 선택: `periods.train` 끝 > T 인 모델은 고르지 않는다.

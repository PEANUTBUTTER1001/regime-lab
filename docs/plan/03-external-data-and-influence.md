# 프로젝트 3 — 외부 자료 수집·RAG·주가 영향력 학습

> 상태: 계획안 · 예상 9~17인주 · 선행: [전체 계획](README.md)의 D-4(출처·보관 권한)와 시각 데이터 계약. 원문 수집 가능 여부는 출처별 확인 전까지 가정하지 않는다.

## 현재 상태·목표

현재 AI 보고서는 백테스트의 **집계 수치**를 설명하고, 모닝 브리핑은 데이터 부족 자리다. 기사·공시·SNS를 자동 수집해 학습·검색·영향력 분석하는 경로는 없다. 사용자는 외부 자료를 수집 또는 취합해 보관하고, 보유 주가 DB와 연결하여 자료의 영향력 가중치를 학습하며, 과거 자료를 RAG로 언제든 다시 사용할 수 있게 하길 원한다.

이 프로젝트의 `영향력`은 우선 **과거 관측 데이터에서의 예측 관련성**으로 정의한다. 외부 자료가 가격 변동의 원인이라는 인과 주장이나 매매 판단으로 표현하지 않는다.

## 작업 ⑦ — 외부 자료 취합·출처와 시각 보존 (3~6인주)

### 소스 계약

1. 기사, 공시, SNS의 구체적 공급원과 접근 방식(API·허가된 파일·크롤링 등), 수집 허용 범위, 원문/요약 보관·재표시 권한, 호출 제한을 D-4에서 출처별로 확인한다. 허가되지 않은 원문을 저장하지 않는다.
2. 자료마다 출처명·원본 식별자/URL·제목/허용된 본문·게시 시각·수집 시각·수정 시각·언어·대상 종목/시장·수집 상태를 보관한다. 원본이 수정되면 이전/새 버전의 관계를 기록한다.
3. 중복 기사, 공시 정정, SNS 삭제·재게시, 출처 부재, 동일 내용 재전송을 처리한다. 종목 태깅은 근거(종목 코드·명칭·문맥)를 기록하고 모호한 매핑은 미확정으로 둔다.
4. **당시 사용 가능 시각**은 게시 시각만으로 단정하지 않는다. 게시 시각, 실제 수집 시각, 모델이 사용할 수 있었던 시각을 분리하고 지연 수집 자료의 소급 사용을 막는다.
5. 수집기는 실패·재시도·중복 실행을 기록하고 원본 시세 데이터와 별도로 저장한다. 저장 형식·보관 위치·새 외부 의존성은 `AGENTS.md` §9의 결정 대상이다.

**완료 기준:** 허가된 샘플 출처마다 자료를 재취합해도 중복이 증가하지 않고, 출처·시각·권한·품질 상태를 추적할 수 있다. 수집 실패가 빈 정상 데이터로 위장되지 않는다.

## 작업 ⑧ — 과거 자료 보관과 RAG (2~4인주)

- 승인된 자료만 검색 가능한 기록으로 만든다. 검색 단위는 출처·시각·종목/시장·자료 버전으로 추적 가능해야 한다. 원문 보관이 금지된 소스는 허용된 메타데이터·요약·링크만 저장한다.
- RAG는 사용자의 질문이나 브리핑에 맞는 **과거 근거를 검색**하는 용도다. 검색 인덱스/임베딩과 영향력 가중치·예측 모델은 다른 산출물이며, 새 자료·정정·삭제 요청 시 각각의 갱신 범위를 추적한다.
- 검색 결과는 원출처 링크·게시 시각·자료 버전·검색 근거를 돌려주고, 근거가 없으면 없다고 표시한다. 회수된 자료를 근거 없이 LLM의 사실로 확장하지 않는다.
- 색인 모델·보관 방식·원문 사용 권한·보존 기간은 D-4 이후 선택한다. 별도 벡터 DB나 신규 서비스는 필요성이 확인되기 전까지 전제하지 않는다.

### 화면에서 보이는 모습

- **자료 기록 화면:** 출처 유형(기사/공시/SNS), 기간, 종목/시장, 수집·품질 상태 필터. 목록은 제목/허용된 요약, 게시·수집 시각, 출처를 보인다.
- **자료 상세/검색 결과:** 원문 링크, 정정 여부, 종목 연결 이유, 분석에 사용 가능했던 시각을 보인다. 권한상 원문을 보여줄 수 없다면 메타데이터만 표시한다.
- **RAG 검색:** 질문/검색어에 맞는 과거 자료와 인용 가능한 근거 목록을 먼저 보여준다. 출처 없는 LLM 설명은 자료로 취급하지 않는다.

**완료 기준:** 같은 질의에서 인용 자료의 원출처·버전을 추적할 수 있고, 정정·삭제/보관 만료 자료가 검색·브리핑에 그대로 남지 않는다. 접근 가능한 데이터 범위가 출처 권한과 일치한다.

## 작업 ⑨ — 비정형 자료의 영향력·가중치 학습 (4~7인주)

### 시점 결합과 학습

1. 자료를 사용할 수 있었던 시각부터 **이후의** 주가 봉/구간에만 연결한다. 장 마감 뒤 게시물과 휴장일 게시물은 다음 사용 가능 봉으로 넘긴다. 같은 날짜라는 이유만으로 장 종료 후 기사를 오전 가격에 붙이지 않는다.
2. 자료의 종목/시장 연결, 주제, 방향성 등 학습 입력을 정의한다. 모델이 사용한 텍스트 표현·추출 버전·처리 실패를 기록한다. LLM이 만든 분류는 검증 가능한 특징이며 가격 효과의 사실값이 아니다.
3. `영향력`의 대상(예: 이후 N봉 변화, 지수 대비 변화, 변동성)을 D-4 및 프로젝트 2의 예측 봉/구간과 일치시키거나 별도 버전으로 명시한다. 발표 시점의 가격·시장 상태를 통제하는 비교 기준을 두어 무조건적인 사건 효과로 해석하지 않는다.
4. 학습/검증/최종 평가를 시간 순서로 분할하고 동일 사건의 중복 기사·후속 정정을 서로 다른 구간에 누출시키지 않는다. 종목과 시장 공통 사건의 중복 반영도 검사한다.
5. 출력은 자료/유형/종목·봉 단위별 **학습된 가중치 또는 기여도**, 표본 수, 평가 기간, 불확실성을 함께 제시한다. 특정 수치가 인과 효과나 미래 수익 보장은 아니라는 설명을 붙인다.

### 화면에서 보이는 모습

- **영향력 분석:** 선택 종목·봉 단위·기간에서 자료 사건을 실제 가격 차트의 과거 시점에 표시한다. 사건 선택 시 게시/사용 가능 시각, 출처, 모델 버전, 평가 표본과 관련성 수치를 연다.
- **가중치 표:** 자료 유형/주제별 학습 가중치와 방향, 표본 수, 별도 평가 결과를 함께 표시한다. 의미가 불안정하거나 표본이 부족한 값은 결론으로 강조하지 않는다.
- 원문 접근이 허용되지 않은 자료는 출처 링크·허용된 요약만 표시한다. 분석 계산은 엔진에서 하고 웹은 API 결과만 표시한다.

**완료 기준:** 합성 사건에서 장중/장후·지연 수집 경계가 올바르고, 미래 기사 제거 시 과거 가중치 입력이 변하지 않는다. 실제 후속 평가에서 단순 가격 기준선과 비교한 결과, 표본 수·기간·모델 버전이 함께 나온다.

## 책임·의존성 및 동작 보존

| 역할 | 추가 책임 | 보존할 동작·검증 |
|---|---|---|
| 인프라 | 허가된 소스 접근·보관·검색 색인·권한/시각 메타데이터 | 원본 주가 데이터 무변경, 키·원문 노출 제한 |
| 도메인 | 시점 결합·사건 특징·가중치 평가 | 미래 사건 누출 방지, 계산의 결정성 |
| 유스케이스 | 수집/색인/학습 실행과 상태·버전 관리 | 기존 분석 실행과 독립된 실패 표시 |
| API·웹 | 허가된 자료·근거·평가 결과 제공·표시 | 기존 LLM 보고서의 집계 전송·숫자 검증 유지 |

신규 모듈의 위치·외부 서비스와 의존성 방향은 구현 전에 제안해 승인받는다. 기존 `api/src/regime_api/llm/service.py`의 알려진 예외를 이 기능을 이유로 늘리지 않는다.

## 위험·결정 대기

- D-4: 구체적 공급원, 원문 보관·검색 허가, SNS 개인정보와 정정·삭제 정책, 학습 대상과 종목 연결 기준.
- 취합 가능한 기간이 일봉 5년/1분봉 약 1.5년과 겹치지 않으면 해당 기간의 영향력 학습은 할 수 없다. **과거 외부 자료가 실제로 확보되는지** 먼저 확인한다.
- 공개 시각이 불명확한 자료는 시점별 학습에서 제외하거나 보수적인 이용 가능 시각을 둔다.
- 영향력은 상관·예측 관련성이지 인과 추정 결과가 아니다. 유의한 개선이 없으면 가중치를 통합 예측에 강제로 적용하지 않는다.

# 프로젝트 2 — 선택 봉 단위별 주가 예측·과거 검증

> 상태: 계획안 · 예상 8~15인주 · 선행: [전체 계획](README.md)의 범위 변경 결정과 1분봉 데이터 실사. **분봉 예측·검증**을 다루며, 분봉 체결 백테스트는 D-3 결정 전까지 포함하지 않는다.

## 현재 상태·목표

현재 엔진 준비 프레임·지표·체결은 일봉 중심이고, 기존 SRS는 국내 주식 1분봉과 가격 예측을 명시적으로 제외한다. 사용자는 보유한 최근 약 5년 코스피 전 종목 일봉과 최근 약 1.5년 코스피 전 종목 1분봉으로, **선택한 봉(예: 1분, 1시간, 3시간, 1일)**의 미래 예상 캔들 또는 흐름을 보고 싶다. 1분봉도 예측과 과거 검증의 대상이다.

모델이 구현됐다는 사실과 유용한 예측이라는 주장은 다르다. 이 프로젝트의 완료 기준은 먼저 데이터 계약, 시간 누출 없는 학습·검증, 실제/예상 구분 표시를 충족하는 것이다. 정확도 목표와 상용 수준의 신뢰성은 측정 후 별도 결정한다.

## 작업 ④ — 1분봉 실사·정규화·시간봉 생성 (2~4인주)

1. 원본을 **읽기 전용**으로 확인한다: 저장 위치·포맷, 거래소/종목 코드, 시각의 시간대, OHLCV 단위, 수정주가 여부, 중복·결측·거래정지·상장폐지 처리, 실제 최초/최종 시각, 일봉과의 연결 가능 범위. `regime.duckdb`는 열지 않는다.
2. 종목·시각 키의 유일성과 시장 거래 세션을 기준으로 1분 데이터를 정렬한다. 초 단위 반올림, 장 전후 체결, 부분 봉, 거래가 없는 분을 어떻게 다룰지 **원본을 덮어쓰지 않고** 정규화 계약에 기록한다.
3. 1시간·3시간봉의 시작점을 거래일 세션에 고정한다. 장 경계를 넘어 다른 날을 한 봉으로 묶지 않는다. 마지막 남은 부분 봉을 포함할지, 확정 봉만 사용할지는 D-2에서 결정한다. OHLC는 시가 첫 값·고가 최댓값·저가 최솟값·종가 마지막 값, 거래량은 합계라는 계약을 샘플로 검증한다.
4. 일봉과 분봉을 무조건 하나의 학습 표로 이어 붙이지 않는다. 관측 빈도·기간·수정주가 기준이 다르므로 선택 봉별 입력 범위와 모델 버전을 기록한다. 일봉 집계 결과와 같은 날 분봉 집계의 가격·거래량 차이도 보고한다.
5. 데이터 지문·스키마 버전·대상 종목 수·결측률·사용 가능 날짜를 기록한다. 새 캐시를 둘 경우 위치와 무효화 규칙을 먼저 정한다.

**완료 기준:** 대표 종목과 거래일에서 1분→1시간/3시간 집계가 수기 계산과 일치하며 장 경계·중복·누락 사례가 명시된다. 1분봉이 실제로 확보되지 않거나 품질 기준을 충족하지 못하면 학습 단계로 넘어가지 않고 자료 부족 상태를 보고한다.

## 작업 ⑤ — 선택 봉별 예측 모델 (4~7인주)

### 학습·추론 계약

- 사용자는 종목(또는 별도로 결정된 대상 범위), 봉 단위, 예측 시작 시점과 미래 **봉 개수**를 선택한다. 필수 예측 출력이 OHLC 전체인지 종가/방향/흐름인지 D-2에서 확정한다. 확정되지 않은 값을 임의의 캔들로 채우지 않는다.
- 1분·시간봉은 정규화한 1분 원본에서, 일봉은 보유 일봉에서 학습·추론한다. 각 예측은 **마지막으로 확정된 입력 봉**과 `as_of` 시각을 남긴다. 미완성 현재 봉을 완성된 값처럼 취급하지 않는다.
- 먼저 재현 가능한 단순 기준선(예: 마지막 값 유지 등)을 두고 선택 모델이 기준선보다 나은지 비교한다. 알고리즘·라이브러리·연산 장치와 추가 의존성은 데이터 규모와 평가 결과를 보고 결정한다. 모델 종류 자체를 성능 보장으로 간주하지 않는다.
- 종목별 데이터와 시장 공통 데이터의 학습 범위를 기록한다. 학습/검증/최종 평가를 시간 순서로 나누고, 전처리·정규화·특성 선택은 각 학습 구간 안에서만 적합한다. 같은 날짜의 다른 종목을 학습에 넣어 해당 날짜 미래를 간접 참조하지 않도록 분할 단위를 검토한다.
- 예측 실패·입력 기간 부족·지원하지 않는 봉 단위의 이유를 반환한다. 해당 모델이 없는 봉 단위에 다른 주기의 예측을 확대·축소해 표시하지 않는다.

### 데이터 기간의 한계

최근 약 1.5년 1분봉은 약 370거래일 분량으로 추정된다(1시간봉 약 2,400개·3시간봉 약 740개 수준, 실사 전 추정). 학습·검증·최종 평가를 시간 순서로 나누고 여러 `as_of` 시점에서 반복 평가할 수 있는 길이다. 다만 일봉 5년보다 짧아 어떤 시장 국면·계절성이 포함되는지는 **미확인**이다. 실사에서 포함 국면을 확인한 뒤 성능을 주장할 범위를 정하고, 포함되지 않은 국면의 성능은 주장하지 않는다. 일봉 5년 성능을 분봉 성능의 대체 근거로 사용하지 않는다.

**완료 기준:** 동일한 데이터·설정·시드로 예측이 재현되고, 예측 시점 이후 입력을 제거해도 그 시점의 예측이 변하지 않는다. 최소한 선택 봉별 기준선과 모델의 후속 구간 성능을 비교할 수 있다.

## 작업 ⑥ — 과거 예측 검증·회색 차트 (2~4인주)

### 검증 흐름

1. 과거 여러 `as_of` 시점에서 당시 알 수 있었던 봉만으로 예측을 만든 뒤, 해당 미래 구간의 실제 봉과 비교한다. 여러 시점의 반복 평가는 시간 순서를 지킨다.
2. 확정된 예측 대상에 맞는 오차·방향·캔들 유효성 지표를 정한다. 봉 단위·예측 봉 개수·종목·평가 기간별 표본 수와 기준선 대비 결과를 함께 보여준다. 현재 **거래 승률**과 예측 정확도를 같은 지표처럼 표시하지 않는다.
3. 검증에 사용된 실측 봉을 학습에 반영한 뒤 같은 시점 예측으로 재평가하지 않는다. 모델 업데이트 시에는 새 버전과 새 평가 구간을 분리한다.
4. 모든 예측 결과에 `as_of`, 데이터 지문, 봉 단위, 미래 봉 개수, 모델 버전, 실패/결측 정보를 연결한다. 저장 형식·API 계약은 사용자 승인 후 확정한다.

### 화면에서 보이는 모습

- **종목 상세의 예측 영역:** 종목과 봉 단위 선택(지원되는 1분·1시간·3시간·1일 등), 예측 봉 개수 입력, 데이터 사용 가능 기간과 마지막 확정 봉을 표시한다.
- 실제 봉은 기존 차트 스타일을 유지하고, 미래 구간의 예상 캔들/흐름은 **회색**으로 표시한다. 경계선, 다른 선 종류/채움, `예상` 범례·툴팁·텍스트 고지를 함께 써서 색만으로 구별하지 않는다. 모델이 OHLC 전체를 출력하지 않으면 가짜 캔들을 그리지 않고 흐름 선으로 표현한다.
- **검증 보기:** 과거 예측을 같은 시점의 실제 결과와 겹쳐 비교하고, 봉별 오차·평가 기간·표본 수·기준선 비교 표를 제공한다. 최신 미래 구간에는 아직 검증되지 않았음을 표시한다.
- 데이터가 부족하면 빈 회색 캔들 대신 `데이터 부족`과 지원 가능 봉·기간을 안내한다. 한국어·영어 UI를 함께 준비한다.

**완료 기준:** 차트에서 실제/예상 경계와 `as_of`가 명확하고, 선택 봉에 맞는 예측·검증만 표시된다. 화면 수치가 API의 엔진 계산과 일치하며 접근성·반응형 검수가 통과한다.

## 책임·의존성 및 동작 보존

| 역할 | 추가 또는 변경될 책임 | 보존할 동작·검증 |
|---|---|---|
| 데이터 인프라 | 1분봉 로딩·정규화·집계·지문·모델 아티팩트 저장 | 원본 무변경, 기존 일봉 `prepare` 결과 불변 |
| 엔진 도메인 | 봉 계약·시점별 특성·예측 검증 계산 | 종목별 계산, 미래참조 절단 불변 |
| 유스케이스 | 학습·추론·검증 실행, 버전·상태 관리 | 기존 백테스트 실행·취소 정책과 충돌 없음 |
| API·웹 | 검증된 결과 계약, 봉 선택과 차트 표시 | 계산은 엔진만, 화면은 JSON 표시만 수행 |

신규 역할/모듈·모델 라이브러리·결과 저장 계약은 `AGENTS.md` §9의 사전 결정 대상이다. 구조를 확정하기 전에 기존 엔진·API 회귀 테스트를 기준선으로 기록한다.

## 위험·결정 대기

- D-2: 미래 봉 개수, OHLC 전체/방향/흐름, 부분 봉, 지원 봉 목록.
- D-3: 분봉 **체결 백테스트**를 요구하는지. 이 계획은 분봉 **예측·검증**만 포함한다.
- 짧은 분봉 기간, 수정주가/원주가 차이, 시장 휴장·거래정지, 종목별 누락이 평가를 왜곡할 수 있다.
- 예측 캔들의 가격 표시는 현재 `AGENTS.md`의 목표가 문구 제한과 경계가 있다. 사용자 승인 전 제품 문구와 표시 범위를 확정하지 않는다.

## 목표와 확인된 출발점

현재 제품은 코스피·코스닥 **일봉**의 고정 파라미터 핵심 패턴 5종을 백테스트하고 국면별 성과와 3중 검증을 표시한다. 전략 빌더 입력은 세션 초안으로 유지되지만, 이름 붙인 프리셋의 영구 저장·목록·수정·삭제 기능은 없다. 현재 승률은 집계 포함 거래 중 비용 차감 후 `net_ret > 0`인 비율이며, 기준일 보유 중이라 제외된 거래는 분모에 포함되지 않는다.

사용자가 설명한 추가 데이터는 **최근 약 5년 코스피 전 종목 일봉**과 **최근 약 1.5년 코스피 전 종목 1분봉**이다. 이 데이터의 실제 위치·스키마·기간·누락률은 아직 확인하지 않았다. 기존 저장소의 코스피·코스닥 일봉 범위와 혼동하지 않는다. 원본 `store/`, `multi_tables_db/`는 변경·이동하지 않고 `regime.duckdb`를 열지 않는다.

\* 1인주 = 개발자 1명이 1주 작업하는 양. 데이터 접근 가능, 수집 권한 확보, 연구용 서비스 수준을 가정한 **거친 규모**다. 정확도 목표 달성, 라이선스·인프라 계약, 운영 안정화 비용은 포함하지 않는다. 1명이 순차 진행하면 대략 8~15개월의 작업량이며, 의존성이 없는 화면·자료 조사 일부는 병행할 수 있다.

```text
프로젝트 1 ── 역방향 백테스트·조합 저장 ─────────┐
프로젝트 2 ── 봉 데이터·예측·시점별 검증 ───────┼─→ 프로젝트 4 통합 예측·브리핑
프로젝트 3 ── 외부 자료·시점 정렬·가중치·RAG ───┘
```

프로젝트 1의 탐색 결과는 4의 평가·비교에 연결할 수 있다. 프로젝트 2와 3의 데이터 조사 및 일부 구축은 병행 가능하다. **백테스트의 미래 성과를 예측 시점의 입력 특성으로 넣지 않는다.** 백테스트는 학습 가능한 과거 구간의 탐색·평가 수단이다.

## 공통 사용자 흐름

1. 목표 승률과 탐색 범위(패턴·AND/OR·수치·청산)를 지정하면 도구가 조건 조합을 생성·백테스트해 목표를 충족한 과거 조합을 찾는다(역방향 백테스트). 조합마다 거래 수, 탐색 구간과 별도 평가 구간의 승률, 시도 후보 수, 현재의 3중 검증 상태를 확인한다. 높은 승률만으로 미래 성과를 약속하지 않는다.
2. 찾은 조합을 이름 붙여 저장하고, 전략 빌더로 불러와 다시 실행하거나 수치를 고쳐 새로 저장한다.
3. 종목과 봉 단위를 선택해 실제 봉 옆에 **회색 예상 봉/흐름**을 보고, 같은 봉 단위의 과거 예측과 실제 결과를 비교한다.
4. 기사·공시·SNS 자료를 출처·시각별로 조회하고, 자료가 해당 시점에 알려져 있었는지와 학습된 영향력 가중치를 확인한다.
5. 지정 시각의 브리핑에서 당일 정보, 과거 근거, 예측의 데이터 한계와 원문 출처를 확인한다.

## 공통 품질 규칙

- 모든 조건 계산·예측·이벤트 결합은 당시 알 수 있던 데이터만 사용한다. 뉴스에는 게시 시각과 실제 수집·이용 가능 시각을 구분한다.
- 탐색/학습과 최종 평가는 시간상 분리하고, 사용한 후보 수·모델 버전·데이터 지문·시드를 기록한다. 목표 승률 탐색의 평가 구간을 재탐색에 반복 사용하지 않는다.
- 예측은 실제 데이터와 색·선·범례·문구로 분리한다. 결과에는 기간, 표본 수, 실패/데이터 부족 상태와 비권유 고지를 함께 둔다.
- 기존 일봉 백테스트와 3중 검증의 의미를 조용히 바꾸지 않는다. 분봉 예측 평가 지표는 별도로 정의한다.
- API 키는 파일·브라우저 저장소·로그·응답에 남기지 않는다. LLM에는 승인된 집계·근거만 주고 숫자 대조·권유 표현 차단을 유지한다.
- 화면 문구는 `web/js/i18n.js`의 한국어·영어 키로 관리한다. AI 보고서 본문은 현재 규칙에 따라 한국어다.

## 프로젝트별 착수 순서와 중단 조건

1. **우선 착수:** 프로젝트 1의 데이터·계약 확인. 기존 테스트로 승률 의미를 고정하고 후보 1개당 평가 시간을 잰 뒤, 역방향 백테스트의 탐색 범위·상한과 찾은 조합의 저장 계약을 설계한다.
2. 프로젝트 2는 1분봉 실사에서 시각·종목·OHLCV·누락·수정주가 정합성이 확인돼야 한다. 1분봉 약 1.5년은 일봉 5년보다 짧으므로, 실사로 포함된 시장 국면을 확인하기 전에는 국면 전반에 걸친 분봉 예측 성능을 주장하지 않는다.
3. 프로젝트 3은 외부 자료 출처별 이용·보관 권한과 게시/수집 시각을 확보해야 한다. 확보하지 못한 출처는 연결하지 않는다.
4. 프로젝트 4는 2와 3에서 **시점 누출 없는 평가 결과**가 나온 뒤 통합한다. 선행 모델보다 개선이 확인되지 않으면 통합 모델을 성공으로 표시하지 않는다.

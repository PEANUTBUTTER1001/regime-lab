# 프로젝트 4 — 통합 미래 예측과 지정 시각 오픈 브리핑

> 상태: 계획안 · 예상 8~16인주 · 선행: [전체 계획](README.md)의 프로젝트 2·3에서 시점 누출 없는 데이터와 평가 결과 확보. 브리핑의 자료 수집 계약은 D-4, 실행 시각은 D-5에서 확정한다.

## 현재 상태·목표

현재 결과 화면은 일봉 백테스트와 과거 분석을 표시한다. AI 보고서는 검증된 집계 수치를 한국어로 해설하며, 모닝 브리핑은 데이터 부족 자리다. 이 프로젝트는 앞 단계의 **주가 봉 예측**, **외부 자료의 시점별 특징·가중치**, **과거 조건 탐색 결과**를 연결해 최종 예측을 검증하고, 지정 시각의 외부 자료를 근거로 당일 상황을 요약한다.

통합 예측은 사용자가 선택한 봉 단위에 맞춰 평가한다. 프로젝트 1의 백테스트는 과거 조건의 성과 평가와 비교에 사용한다. **예측하려는 시점 이후에 확정되는 백테스트 성과·외부 자료는 모델 입력으로 넣지 않는다.**

## 작업 ⑩ — 주가·비정형 자료 통합 예측 (4~8인주)

### 데이터·학습 흐름

1. 프로젝트 2의 확정 봉·가격 특징과 프로젝트 3의 자료 특징/가중치를 공통 `as_of` 기준으로 결합한다. 각각의 게시·수집·정정 시각과 봉 확정 시각 중 **실제로 이용 가능했던 시각**을 사용한다.
2. 외부 자료가 없는 종목·시점도 명시적으로 표현한다. `외부 자료 없음`을 `영향 없음`으로 자동 해석하지 않고, 누락률과 대상 범위를 기록한다.
3. 가격만 사용한 모델(프로젝트 2)과 통합 모델을 **같은 종목·봉·기간·예측 길이**에서 비교한다. 자료 결합이 실제 후속 평가에서 개선되지 않으면 통합 모델을 기본 결과로 승격하지 않는다.
4. 과거 탐색 조건/프리셋 결과는 학습 구간 안에서 계산된 요약·실험 조건으로만 사용할 수 있다. 테스트 구간에서 높은 승률로 고른 후보를 같은 테스트 구간의 예측 입력으로 되돌려 쓰지 않는다.
5. 학습·검증·최종 평가는 시간 순서로 분리한다. 모델·가중치·전처리·검색 색인·입력 데이터 지문·시드·봉 단위·예측 길이를 한 예측 버전으로 묶어 추적한다.
6. 정확도가 부족한 봉/종목은 예측을 제공할 수 있어도 **검증 부족** 상태와 기준선 대비 결과를 표시한다. 검증이 불가능한 경우 예측 성공이라고 주장하지 않는다.

### 화면에서 보이는 모습

- 프로젝트 2의 종목 상세 예측 차트에서 `가격 데이터 기준`과 `외부 자료 결합` 결과를 선택·비교한다. 두 결과가 함께 있으면 선 종류·범례로 구분하고, 미래 구간은 모두 실제 봉과 구별되는 회색 계열로 표시한다.
- 예측 카드에는 선택 봉, 미래 봉 개수, 마지막 확정 봉, 모델 버전, 사용된 외부 자료 건수·최근 이용 가능 시각, 기준선 및 가격 단독 모델 대비 평가 결과를 보인다.
- **근거 보기:** 어떤 종류의 과거 자료가 입력됐는지, 인용 가능한 자료의 출처·시각, 학습 가중치 버전을 볼 수 있다. 가중치가 특정 주가 움직임을 확정적으로 만든다는 문구를 쓰지 않는다.
- 실제 결과가 도착하면 같은 `as_of` 예측을 사후 검증 화면에서 비교한다. 예측 값 자체를 사후 재계산해 과거 예측인 것처럼 바꾸지 않는다.

**완료 기준:** 동일 입력 버전으로 예측을 재현할 수 있고, 미래 봉·미래 기사 제거 시 과거 예측이 변하지 않는다. 가격 단독 기준선과 같은 평가 구간에서 비교 결과가 제공된다.

## 작업 ⑪ — 지정 시각 외부 자료 취합·LLM 브리핑 (2~4인주)

### 실행·근거 흐름

1. 사용자가 지정한 **시간대와 시각**, 휴장일·지연 자료 처리, 대상 시장/종목 범위와 재생성 정책을 D-5에서 확정한다. 현재 제품의 한글 보고서 규칙을 따르며 영어 UI 선택과 보고서 본문 언어의 관계도 명시한다.
2. 지정 시각의 작업은 허가된 외부 자료 수집·품질 확인 → 시점이 맞는 주가·자료 집계 → 결정적인 근거 JSON 생성 → LLM 요약 → 숫자·출처·권유 표현 검증 → 발행 순서로 수행한다. 자료가 없거나 검증에 실패하면 브리핑을 발행하지 않고 상태·사유를 보인다.
3. 브리핑에는 생성 기준 시각, 자료별 게시·수집 시각, 출처 링크/식별자, 데이터 범위, 사용한 모델·가중치 버전, 과거 조건부 분석과 예측의 구분을 남긴다. LLM이 입력에 없는 수치·기사·출처를 지어내면 거부하거나 검증된 템플릿/데이터 부족 상태로 대체한다.
4. 현재 AI 보고서의 **집계 수치만 전송·숫자 대조·권유 표현 차단·키 비노출** 원칙을 약화하지 않는다. 현 규칙에서는 기사 원문·요약·출처 목록을 LLM에 보내지 않는다. 외부 자료를 LLM 문장 생성의 입력으로 쓰는 요구를 구현하려면, 전송할 자료의 최소 범위와 출처별 권한을 정하고 사용자 승인으로 SRS·`/agents-md` 규칙을 먼저 개정한다. 그 전에는 LLM에 검증된 집계 수치만 전송하고, 출처 목록은 서버가 템플릿으로 별도 표시한다.
5. 같은 시각의 중복 실행은 한 브리핑으로 귀결되게 하고, 수집 실패·LLM 실패·재시작·재시도에서 상태를 복구할 수 있게 한다. 실제 운영 스케줄러의 방식·서비스·의존성은 별도 승인 대상이다.

### 화면에서 보이는 모습

- 현재 `브리핑` 메뉴의 `Data unavailable` 자리를 **오늘의 상황 브리핑**으로 연결한다. 상단에는 대상 날짜/생성 기준 시각, 자료 최신성, 상태(준비 중·완료·자료 부족·검증 실패)를 표시한다.
- 본문은 핵심 상황 요약, 외부 자료 근거 목록, 과거 데이터 분석, 예측 정보가 있다면 별도 `예상` 구역으로 분리한다. 각 근거에서 원출처와 시각으로 이동할 수 있다.
- 원본 근거를 찾을 수 없는 문장이나 자료 권한상 보여줄 수 없는 전문은 표시하지 않는다. 오래된 브리핑은 `과거 브리핑`으로 구분하며 새 자료가 들어왔다고 이미 발행한 내용이 조용히 변하지 않는다.
- LLM 키가 없거나 공급사가 실패하면 검증된 수치·출처만으로 구성한 템플릿 또는 명확한 실패 상태를 표시한다. API 키는 설정 화면의 현재 메모리 보관 규칙을 따른다.

**완료 기준:** 동일한 확정 입력·버전으로 근거가 같은 브리핑을 재생성할 수 있고, 모든 외부 사실의 출처를 확인할 수 있다. 없는 숫자·출처·권유 문구와 공급사 오류의 키 조각이 응답·로그에 나타나지 않는다.

## 작업 ⑫ — 통합 회귀·릴리스 검증 (2~4인주)

| 검증 축 | 반드시 확인할 사례 |
|---|---|
| 기존 동작 | 엔진·API 전체 테스트, 핵심 5종 기본 전략 성과와 기존 `run_id` 조회, 현 보고서 숫자 검증 |
| 시점 누출 | 봉·기사·가중치의 절단 불변, 장후 기사, 지연 수집, 정정 기사, 모델 재학습 후 과거 예측 보존 |
| 예측 평가 | 같은 구간의 가격 단독/통합/단순 기준선 비교, 봉별·종목별 표본 수와 실패 상태 |
| 브리핑 | 정시·휴장일·중복·지연·재시작·LLM 오류·출처 누락·키 가림 |
| 사용자 흐름 | 프리셋 → 목표 승률 탐색 → 봉 선택·예측 → 근거/RAG → 브리핑, 한국어·영어 UI, 키보드·좁은 화면 |
| 데이터·운영 | 원본 무변경, 허용된 자료만 보관, 입력 지문·모델 버전·브리핑 버전으로 결과 재현 |

**완료 기준:** 정해진 수용 사례가 통과하고, 미충족 항목은 사용자에게 실패/제한으로 표시된다. 성능 측정은 데이터 규모 실사 후 목표값을 정하며, 학습 시간·추론 대기·브리핑 지연을 기록한다.

## 위험·결정 대기

- **기존 명세 충돌:** 현재 SRS는 가격 예측·실시간 자료 수집·운영 스케줄러를 제외한다. 승인된 명세 개정 전에는 구현하지 않는다.
- **정확도·자료 기간:** 약 1.5년 분봉과 실제 확보 가능한 과거 외부 자료의 교집합이 작으면 통합 모델의 독립 평가가 불가능할 수 있다. 결과는 모델 실패/검증 부족으로 정직하게 표시한다.
- **브리핑 권한:** 허가 없는 원문 저장·전송·재표시를 계획에 포함하지 않는다. 출처별 이용 조건이 확정되어야 한다.
- **표시 경계:** 미래 가격형 캔들 및 종목 화면 문구는 기존 목표가 금지 규칙과 맞물린다. 사용자 승인과 필요 시 `/agents-md` 개정으로 허용 범위를 확정한다.
- **D-5:** 브리핑 시각/시간대/휴장일, 발행 범위, 재실행·실패 처리. D-2의 예측 봉 개수와 필수 출력도 확정돼야 한다.

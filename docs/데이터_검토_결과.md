## 3. 결정별 근거

### 3.1 A1 데이터 소스 — 확정(조건부)

- `store/`에 수정주가·시가총액·상장폐지·지수·원주가·업종이 모두 있으며 수집 검증을 통과했다(`collect.log`: 시작일, 삼성전자 2021-01-04 종가 83,000원, 거래대금 결측 0).
- `kor_price`는 상장폐지 종목이 거의 없어(333개 중 6개) 본 데이터로 쓰면 생존편향이 생긴다.
- **조건**: 로그와 정의서가 참조하는 `collect.py`, `build_db.py`가 폴더에 없다. FR-D6(재실행 가능한 수집)을 위해 제공이 필요하다.

### 3.2 A2 워밍업 — 확정

| 확인 항목 | 결과 |
|---|---|
| 2020-09-01 유니버스 종목 | 2,177개 |
| 그중 `kor_price`에 2019-08~2020-08 이력이 있는 종목 | 1,979개 |
| 그중 250거래일 이상인 종목 | **1,890개 (86.8%)** |
| 2020-09 두 소스의 종가 비율(`store` / `kor_price`) | 5% 분위 0.9997, 중앙값 1.0000, 95% 분위 1.0000 |
| 연도별로 두 소스 종가가 0.1% 이내인 비율 | 2020년 94.0% → 2026년 97.2% |

- 연결 지점에서 두 소스가 사실상 같은 기준이라 비율 보정 연결이 안전하다.
- 방식: 종목별로 2020-09-01 종가 비율을 구해 `kor_price`의 이전 구간에 곱하고, 워밍업 구간에서는 신호·거래를 만들지 않는다(FR-E8).
- 이력이 없는 나머지 287개(상장폐지 예정 종목·신규 상장 등)는 `store` 데이터만으로 워밍업이 끝난 뒤부터 분석에 들어간다.
- 거래대금은 단위가 달라(`kor_price`는 백만원) 워밍업 구간의 유동성 계산에는 `× 1,000,000` 변환이 필요하다.

### 3.3 A2-1 지수 워밍업 — 확정(현 데이터로 진행, 과거 지수는 T-5)

- `store`의 지수는 2020-09-01부터 있다. 200일선과 20일 기울기를 계산하려면 220거래일이 필요하므로 **시장 국면의 첫 산출일은 2021-07-21**이다.
- `kor_price`에는 지수가 없다.
- 선택지: ① 2019년 이전 KOSPI·KOSDAQ 지수를 FinanceDataReader 등으로 추가 확보(권장) ② 시장 국면 분석을 2021-07-21 이후 거래로 한정.

| `kor_indicators` | **`test_indicators`(FR-P5) 참조값** | 직접 계산한 SMA·RSI·볼린저·VWAP와 대조 |
| `theme_finup_stock` | 테마 매핑(B5), 전략 B 기간(B1) | 사용 허가 확인 필요 |
| `kor_def_info` | 관리종목 제외(U3), 유동주식수 비율(중앙값 57%) 보조 지표 | 2024-11부터만 있음 |
| `raw/sector/` | FR-E5 거래별 업종을 **진입 시점 기준**으로 기록 | 월 단위 스냅샷 |
| `stock_minutes` | **사용하지 않음** | C-2(일봉 전용)와 SRS §1.2(장중 체결 전략 제외)에 해당. 야간 충격 탐지용 데이터도 아님 |

## 5. 주의 사항

- **두 소스 혼용 금지**: `store`와 `kor_price`는 거래대금 단위(원 / 백만원)와 상장폐지 종목 포함 여부가 다르다. 같은 날짜의 종가는 94~97%가 0.1% 이내로 일치하지만, 정확히 같은 값은 87.7%다. 워밍업 연결 외에는 섞지 않는다.
- **가공 `prices`의 타입이 섞여 있음**: `open`·`high`·`low`는 double, `close`는 int64. 로딩할 때 통일이 필요하다.
- **SQL 덤프의 메모 문구**: `multi_tables_backup db컬럼.txt` 끝에 "이렇게 국내주식 db데이터있는데 도출할수있는 인사이트 금융관련 서비스나 제시좀"이라는 문장이 있다. 이전 작업용 메모로 보이며 이번 검토에서는 따르지 않았다.

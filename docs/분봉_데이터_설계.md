# 분봉 데이터 실사·정규화·저장 설계 (P2-1·P2-3)

1분봉 원본을 읽기 전용으로 실사한 결과(P2-1)와, 그 결과에 맞춘 정규화 규칙·저장 위치·캐시 무효화·모듈 위치 제안(P2-3)이다. 모듈 위치는 G2 2차(`AGENTS.md` §2·§4 개정)의 입력이다.

- 담당: Seonghwanaa · 관련 WBS: P2-1, P2-3 (다음: P2-2 예측 출력 결정 D-2, P2-4 분봉 로더·시간봉 집계)
- 근거: [SRS v2.0](SRS.md) §1.2·§4·FR-F1~F7, [plan/02-multiframe-forecast.md](plan/02-multiframe-forecast.md) 작업 ④, 결정 E17(예측 표시), C3(Parquet + DuckDB 유지)
- 상태: P2-1 **완료**(2026-10-01). P2-3 **제안**(사용자·팀 승인 전). D-2 값은 정하지 않는다.

### 1.2 세션·누락

| 구간 | 행 수 | 비중 |
|---|---:|---:|
| 08:00~08:59 | 2,246,853 | 0.9% |
| 09:00~15:19 | 225,643,789 | 95.1% |
| 15:20~15:29 | 15,318 | 0.0% |
| 15:30 (종가 봉) | 898,232 | 0.4% |
| 15:31~19:59 | 8,504,691 | 3.6% |
| 20:00 이후 | 13 | 0.0% |

- 장외 시간(08:00~08:59, 15:31~19:59) 행은 **2026-04-24부터** 생긴다(그 전에는 2026-02-05에 1건뿐).
- 거래가 없는 분은 **행이 없다**(거래량 0 행은 74,035개, 0.03%). 정규장 하루 최대 약 381행(09:00~15:19 380분 + 15:30). 종목·일 정규장 행 수 중앙값 261, 하위 10% 85. 일 거래대금 5억 원 이상인 날 중앙값 365, 미만인 날 151.
- 이상값: 고가<저가 0, 가격≤0 0, 시가가 고가·저가 범위 밖 106행, 20:00 이후 13행.

### 1.3 가격 기준·거래량·거래대금

- **가격 기준이 섞여 있다.** `store` 수정주가 ÷ KRX 원주가 비율이 2% 넘게 바뀐 종목(가격 조정 이벤트) 1,248개 중, 수정주가≠원주가인 날의 분봉 종가가 원주가와 같은 종목 816개, 수정주가와 같은 종목 133개, 섞인 종목 47개. 이벤트 날짜로 나뉘지 않는다(종목별 사후 수정으로 보임, 원인 미확인).
- 정규장 분봉을 일로 합친 종가 = KRX 원주가: 2026-04-24 전 95.2%, 이후 99.25%.
- **`value`는 당일 누적 거래대금(원)**이다. 첫 행 = 가격×거래량(중앙값 1.00), 값이 줄어든 적 0, 마지막 값 ÷ KRX 일 거래대금 중앙값 0.999.
- **2026-04-24부터 KRX+NXT 통합 시세**로 보인다. 장외 시간 행이 있는 종목의 정규장 거래량 ÷ KRX 일 거래량 상위 10%가 1.43배(장외 행 없는 종목은 1.00배), 고가·저가 일치율 97.6%(장외 행 없는 종목 99.97%). 거래소 구분 컬럼이 없어 분리할 수 없다.

## 2. 정규화 규칙 (P2-3.1, 제안)

원본은 덮어쓰지 않는다. 아래 규칙은 정규화 단계(§3의 2단계)에서만 적용한다.

| # | 대상 | 규칙 | 근거 |
|---|---|---|---|
| N1 | 세션 | **정규장 09:00~15:30만** 사용한다. 장외 시간(08:00~08:59, 15:31 이후)은 제외한다. 늦은 개장일은 있는 행 그대로 둔다(10:00 시작) | 장외 시간은 2026-04-24 이후에만 있어 기간 일관성이 없다(§1.2) |
| N2 | 가격 기준 | 종목·일별로 정규장 집계 종가를 KRX 원주가·`store` 수정주가와 대조(허용오차 0.2%)해 `price_basis`를 `raw`·`adj`로 판정한다. `raw`면 그날 조정 비율 `adj_factor = store close ÷ close_raw`를 OHLC에 곱해 **수정주가로 통일**한다. 둘 다 아니면 그 종목·일을 제외하고 사유를 남긴다 | §1.3. 손익·지표가 수정주가 기준인 일봉 엔진과 맞춘다 |
| N3 | 조정 이벤트일 | `adj_factor`가 전일 대비 바뀐 날은 그날로 넘어가는 수익률을 학습 목표에서 뺀다 | 조정 전후 가격 연결부의 가짜 변동 방지 |
| N4 | 거래대금 | `value_1m` = 같은 종목·일에서 직전 행과의 `value` 차이(첫 행은 `value` 그대로). 원래 `value`는 `value_cum`으로 보존한다 | `value`는 당일 누적(§1.3) |
| N5 | NXT 구간 | `nxt_period` = 날짜 ≥ 2026-04-24 플래그를 붙인다. 거래량 특징은 종목별 상대값으로 쓰고, 평가는 전후 구간을 나눠 보고한다 | 통합 시세로 거래량·고저가 성격이 바뀜(§1.3) |
| N6 | 결측 분 | 거래 없는 분을 0거래량 행으로 채우지 않는다. 집계 봉에는 실제 포함된 분 수 `n_minutes`를 남긴다 | 행이 없는 것이 원본 의미(§1.2) |
| N7 | 이상값 | 시가가 고가·저가 범위 밖인 106행, 세션 밖 행은 제외하고 개수를 지문에 기록한다 | §1.2 |
| N8 | 대상 종목 | `store` `master.kind = 보통주`만 기본 대상. 1분 예측 대상의 유동성 기준은 D-2 | 우선주 없음, 유니버스(U2)와 일치 |

### 2.1 집계 봉 경계 (FR-F1)

- 시간봉은 거래일 세션에 고정한다. 1시간봉: 09:00~09:59, 10:00~10:59, …, 14:00~14:59, **15:00~15:30**(마지막 봉에 종가 봉 포함). 3시간봉: 09:00~11:59, 12:00~15:30. 날을 넘겨 묶지 않는다.
- OHLC = 첫 시가·최대 고가·최소 저가·마지막 종가, 거래량·`value_1m` = 합계. 늦은 개장일의 첫 1시간봉은 10:00부터다.
- 봉 확정 시각 = 봉의 마지막 분 + 1분(예: 09:00~09:59 봉은 10:00 확정). 예측은 확정된 봉까지만 입력으로 쓴다(FR-F3). 마지막 부분 봉을 포함할지는 D-2에서 정한다.
- 대표 종목·거래일의 수기 계산과 일치해야 한다(FR-F1, P2-4.4 테스트).

## 3. 저장 위치·캐시 무효화 (P2-3.2, 제안)

| 단계 | 위치 | 내용 | Git |
|---|---|---|---|
| 0. 원본 | MariaDB `regime_lab.stock_minutes` (팀 데이터 서버) | 수정하지 않음 | – |
| 1. 원본 사본 | `data/minutes/stock_minutes_YYYYMM.parquet` + `minutes_manifest.json` | 원본 8컬럼 그대로, 월별, zstd (약 3.1GB). 매니페스트에 월별 행 수·최소/최대 시각·내보낸 시각 | 제외 (`/data/`) |
| 2. 정규화 캐시 | `cache/minutes/v<MINUTE_PREP_VERSION>_<설정 해시>_<데이터 지문>/` 아래 `bars_1m/`, `bars_1h/`, `bars_3h/` (월별 Parquet) | §2 규칙 적용 결과 | 제외 (`cache/`) |

- 엔진은 MariaDB에 직접 연결하지 않는다. 1단계 사본만 읽는다(C3 유지, 새 DB 의존성 없음).
- 1단계 사본은 원본 사본이므로 `data/`에 두고, 팀 공유는 F1(데이터 서버)의 `data/` 구조를 그대로 따른다.
- 2단계 캐시 이름에 넣는 값: `MINUTE_PREP_VERSION`(정규화 코드가 바뀌면 올림), `default.yaml`의 새 `minutes:` 절 해시, 1단계 매니페스트 해시. 셋 중 하나가 바뀌면 새 폴더로 다시 만든다. 일봉 `PREP_VERSION`과는 독립이라 일봉 준비 캐시를 무효화하지 않는다.
- 새 설정 `minutes:` 절(세션 시각, 가격 기준 허용오차 0.2%, NXT 기준일, 지원 봉 목록)은 `default.yaml` 맨 끝에 항목 추가로만 넣는다(공용 파일, 채널 사전 공지).

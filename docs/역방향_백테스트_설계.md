# 역방향 백테스트 설계 (P1)

목표 성과(예: 승률 55% 이상, 거래 300건 이상)를 입력하면 그 조건을 만족하는 전략 조합을 찾아 주는 기능이다. 정방향 백테스트(`execute`)를 후보마다 반복 실행하고, 다중검정 보정으로 우연히 좋아 보이는 후보를 거른다.

- 담당: 홍성민 · 관련 WBS: P1-1 ~ P1-11 · 결정: [구현_전_결정사항 §5.2](구현_전_결정사항.md)
- **범위 충돌:** SRS §1.3은 "파라미터 최적화·그리드 서치"를 제외 범위로 둔다. 이 기능은 G1(확장 범위 승인·SRS 개정) 승인 뒤 본 구현에 들어간다.

## 1. 현 계약 (P1-1.1, 2026-10-01 `develop` 7f9700f 기준)

### 1.1 전략 입력

엔진 `Strategy.from_dict`(구조 검증) → `Strategy.validate(cfg)`(값 검증). API는 `schemas.StrategyIn`(pydantic 엄격 모드, 알 수 없는 키 금지)이 1차 관문이다.

| 필드 | 타입·범위 | 생략 시 | 비고 |
|---|---|---|---|
| `name` | `^[A-Za-z0-9_\-]{1,64}$` | 필수 | 한 요청 안에서 중복 금지 |
| `patterns` | 핵심 5종 중 1개 이상, 중복 금지 | 필수 | `ma_cross_5_20`, `breakout_20d`, `breakout_vol`, `rsi_rebound`, `bb_lower_recover` |
| `combine` | `and` / `or` | `or` | |
| `exit.stop_loss_pct` | -50 ~ -1 또는 null | -8 | 퍼센트 단일 단위(-8 = -8%) |
| `exit.take_profit_pct` | 1 ~ 200 또는 null | 20 | |
| `exit.max_hold_days` | 정수 1 ~ 250 | 20 | |
| `exit.trailing_stop_pct` | null만 | null | |
| `markets` | KOSPI·KOSDAQ 부분집합 | 둘 다 | 진입 신호 필터(E1) |
| `period` | `{start, end}` YYYY-MM-DD, start ≥ 2020-09-01, end ≤ 기준일 | 전체 | 신호일 기준(E2) |
| `min_avg_value_krw` | 정수 ≥ 5억 원 | 5억 원 | |
| `cap_groups` | large·mid·small 부분집합 | 전체 | |

**패턴 수치(RSI 임계값, 거래량 배수 등)는 전략에서 바꿀 수 없다**(C-3, FR-P4). 값은 `engine/config/default.yaml`의 `patterns`에만 있다. 탐색 축에 패턴 수치를 넣으려면 P1-4(패턴 수치 파라미터화)가 먼저 필요하다.

### 1.2 실행·결과

| 계층 | 진입점 | 출력 |
|---|---|---|
| 엔진 | `runs.execute(strategies, prep, cfg, ctx)` | `{"strategies", "results": {이름: trades·skipped·summary·equity·cells_*}, "validation": DataFrame}`. 저장하지 않음 |
| 엔진 | `runs.run_and_save(...)` | `runs/<run_id>/` (meta.json, result.json, validation.parquet, universe.json, strategies/<이름>/*.parquet·summary.json). 임시 폴더에 쓴 뒤 완료 시 이동(E4) |
| API | `POST /runs` (202), `GET /runs`, `GET /runs/{id}`, `POST /runs/{id}/cancel`, `GET /runs/{id}/result` | 동시 실행 1개, 실행 중 요청은 `409 busy`(E4). 한 요청 최대 5전략(`MAX_STRATEGIES`) |

`summary` 지표 키: `trades`, `win_rate`, `mean_ret`, `median_ret`, `mean_hold_ret`, `mean_excess`, `payoff_ratio`, `sharpe`, `mdd`, `total_cost`, `excluded_trades`, `skipped_entries`, `skipped_by_reason`, `exit_by_reason`, `period_start`, `period_end`. 정의는 `backtest/metrics.py`의 `METRIC_DEFS`.

`validation` 열: `fdr_pass`(BH q ≤ 0.10, m = 요청 안 전략 수), `split_judgement`·`split_pass`(2024-02-29 전후), `random_percentile`·`random_pass`(무작위 1,000회 95 백분위), `analysis_target`(셋 다 통과).

### 1.3 승률 정의 (P1-1.2)

`win_rate` = 집계 포함 거래(`end_of_data` 제외) 중 **비용 차감 후 `net_ret > 0`** 인 거래의 비율.

- 손익 0은 승리가 아니다.
- 왕복 비용(0.30%)을 뺀 값 기준이라, 비용보다 작은 이익은 패배다.
- 거래가 없으면 NaN.

회귀 테스트 `engine/tests/test_win_rate.py`: 정의 경계 4건 + 합성 시장(30종목, seed 0)에서 핵심 5종의 거래 수·승률 고정값. 엔진·설정을 바꿔 이 값이 바뀌면 역방향 탐색 결과도 바뀌므로 의도한 변경인지 확인한다.

## 2. 후보당 평가 시간 실측 (P1-1.3)

합성 시장(`engine/tests/synth.py`의 `make_market`, 2019-08-01 ~ 2026-09-18), Apple Silicon, 단일 프로세스. 단위: 초.

| 종목 수 | 전략 | 거래 수 | 신호 | 체결 | 거래 결합 | 요약 | FDR·분할 | 무작위 1,000회 | **합계** |
|---|---|---|---|---|---|---|---|---|---|
| 300 | rsi_rebound | 7,070 | 0.02 | 0.08 | 0.20 | 0.07 | 0.00 | 0.16 | **0.53** |
| 3,000 | rsi_rebound | 70,622 | 0.19 | 0.83 | 1.65 | 0.66 | 0.01 | 2.21 | **5.57** |
| 3,000 | ma_cross_5_20 | 94,761 | 0.34 | 0.89 | 1.99 | 0.70 | 0.02 | 2.60 | **6.55** |
| 3,000 | breakout_20d OR rsi_rebound | 137,371 | 0.18 | 1.04 | 2.55 | 0.72 | 0.04 | 3.44 | **7.96** |

실데이터 참고값(progress/PROGRESS.md): 전종목 단일 전략 12.9초, 핵심 5종 비교(m=5) 74.9초, 최대 메모리 2.39GB.

**결론: 후보 1개당 약 6~13초.** 후보 100개면 10~22분, 500개면 50분~1.8시간이다.

- 시간의 대부분은 무작위 벤치마크(약 40%)와 거래 결합(약 30%, 거래별 지수 수익률 Python 반복)이다.
- 1차 선별은 승률·거래 수·FDR만으로 하고, 무작위 벤치마크는 통과 후보에만 돌리면 후보당 약 3~4초로 줄어든다.
- 시간 비례 요소는 거래 수다. AND 결합·짧은 보유 기간 후보는 더 빠르다.

## 3. P1-2(탐색 범위)로 넘기는 사항

1. 후보 수 상한: 위 실측으로 한 번의 탐색은 **후보 200개 이하(약 20~40분)** 를 권장한다.
2. 패턴 조합: 5종의 공집합 아닌 부분집합 31개 × AND/OR → 중복(1개짜리는 AND=OR)을 빼면 57개.
3. 청산 축: 손절·익절·최대 보유를 몇 단계로 나누면 조합 수가 곱으로 늘어나 상한을 바로 넘는다. 축별 단계 수를 정해야 한다.
4. FDR 가족 크기: 탐색 한 번의 후보 수를 m으로 둔다(E3 확장). 후보가 많을수록 보정이 엄격해진다.
5. 과최적화 방지: 탐색 구간에서 고르고 평가 구간에서 다시 검증한다(P1-5.2). 현 기간 분할일(2024-02-29)을 그대로 쓸지 정한다.
6. 체결: 일봉 다음 거래일 시가(D-3). 분봉 체결은 §8 T-10.
